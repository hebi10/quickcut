# QuickCut

**복잡한 설정 없이 스마트폰과 태블릿에서 바로 편집하고 빠르게 저장하는 오프라인 Android 영상 편집기**

> 현재 단계: 기획 수립. **애플리케이션 소스 코드는 아직 작성하지 않습니다.**

## 제품 목표

1. 앱 실행 → 영상 선택 → 편집 → 갤러리 저장까지 단순한 흐름을 제공합니다.
2. 불필요한 전체 재인코딩을 줄이되, 결과물의 재생 호환성과 정확한 편집을 속도보다 우선합니다.
3. 로그인, 회원가입, 서버, 클라우드, 필수 네트워크 연결 없이 기기 내부에서 작업합니다.
4. 원본 파일을 수정하지 않고 편집 결과를 별도 파일로 저장합니다.

## 범위 및 개발 순서

| 단계 | 범위 | 목표 |
| --- | --- | --- |
| 1차 MVP | 영상 불러오기, 미리보기, 앞뒤 자르기, 분할·삭제, 순서 변경·합치기, 음소거, MP4 저장 | 빠른 편집의 기반 검증 |
| 2차 | 배경음악·볼륨, 텍스트, 회전·크롭, 속도 조절, 실행 취소·재실행 | 실용적인 기본 편집기 |
| 3차 | 간단한 필터, 자막 편집 편의성, 전환 효과 검토, 성능·호환성 고도화 | 완성도 개선 |

단계별 기능은 개발 가능성과 실제 기기 성능 측정 후 조정합니다. 복잡한 AI 기능과 소셜 기능은 초기 범위에서 제외합니다.

## 기본 정책

- 플랫폼: Android 전용
- 구현 방향: Kotlin + Jetpack Compose + AndroidX Media3
- 데이터: 기본적으로 메모리 내 편집 상태 관리. 앱 재시작 후 프로젝트 이어하기는 초기 범위에서 제외
- 갤러리 접근: 사용자 선택 기반 접근 우선
- 내보내기: 지원 가능한 경우 스트림 복사를 사용하고, 필요한 경우 인코딩 수행
- 개인정보: 서버 업로드 없음, 원본 보존, 결과물 명시적 저장
