QuickCut 개인정보처리방침
시행일: 2026년 11월 2일
운영자: hebi (QuickCut 개발자)

1. 기기 내 영상 처리
QuickCut은 사용자가 선택한 영상·음성·촬영 날짜·영상 형식과 길이 등 메타데이터를 자르기, 분할, 연결, 음소거 및 결과 저장을 위해 기기 안에서 처리합니다. 앱 계정이나 로그인이 없으며, 영상을 개발자 서버로 업로드하지 않습니다. 광고·사용 분석 SDK를 사용하지 않으며 앱이 데이터를 자동 전송하지 않습니다.

2. 선택한 파일과 권한
Android 문서 선택기에서 사용자가 고른 영상에만 접근합니다. 전체 사진·영상 보관함, 위치, 연락처, 카메라, 마이크 접근 권한을 요청하지 않습니다. 선택한 파일이 클라우드 문서 제공자에 있으면 해당 제공자가 파일을 내려받을 수 있으며 그 제공자의 정책이 적용됩니다.

3. 기기에 보관하는 설정과 작업 기록
선택한 원본의 URI(파일을 다시 여는 주소), 편집 구간·순서·음소거 설정, 템플릿, 저장 날짜·원본 처리 설정, 이전 편집과 일괄 작업 복구 기록을 앱 내부 저장소에 보관합니다. 자동 Android 앱 데이터 백업은 사용하지 않습니다. 임시 결과는 앱 캐시 또는 갤러리의 임시 항목에 저장하며 완료한 결과는 갤러리의 Movies/QuickCut 폴더에 저장합니다. 정상적인 정리 절차에서 임시 결과를 제거하며, 미완료 작업은 다음 실행 시 복구·정리할 수 있습니다.

4. 로컬 진단과 클립보드
문제 확인을 위해 최근 작업 최대 12건과 실패 작업 최대 6건의 진단을 기기에 보관합니다. 앱 버전, 기기 모델·Android 버전, 코덱·영상 형식·길이·크기, 처리 단계와 시간, 저장 공간, 분류된 오류 정보 등을 포함합니다. 진단에는 원본 URI·경로·파일명·영상 내용·원시 오류 메시지를 넣지 않습니다. 진단은 자동 전송하지 않으며 사용자가 '진단 복사'를 누를 때만 클립보드로 복사됩니다. 이후 사용자가 다른 앱에 붙여넣어 공유하면 해당 앱의 정책이 적용됩니다.

5. 백그라운드 저장과 원본 처리
사용자가 시작한 영상 저장을 다른 앱 사용 중에도 완료하기 위해 진행 알림이 있는 포그라운드 서비스를 사용합니다. 알림에서 진행 상태를 확인하고 저장을 중단할 수 있습니다. 원본은 기본적으로 유지합니다. 원본 휴지통 이동·영구 삭제는 사용자가 해당 옵션을 선택하고 저장 후 Android의 시스템 승인 절차를 거친 경우에 수행합니다. Android 10에서는 원본 자동 처리를 지원하지 않습니다.

6. 삭제와 보관
앱 설정의 데이터 삭제 또는 앱 제거로 내부 설정·템플릿·복구 기록·진단을 삭제할 수 있습니다. 갤러리에 저장한 완성 영상과 원본은 앱 제거 후에도 남을 수 있으므로 갤러리나 파일 관리 앱에서 별도로 관리·삭제해 주세요. 앱이 보관한 기록은 다음 작업과 설정 변경에 따라 갱신되며 진단은 정해진 건수까지만 유지합니다.

7. 외부 수집·공유
QuickCut 앱은 위 데이터를 개발자나 제3자에게 자동 수집·공유하지 않습니다. 앱 내부에 별도 서버, 광고, 분석, 계정 생성 기능이 없습니다. 외부 문서 제공자 사용, 클립보드 공유, 사용자가 직접 보내는 문의 이메일은 사용자가 선택한 외부 서비스에서 처리됩니다.
