# 01. 제품 요구사항

- 상태: 기획 초안 v0.1
- 기준일: 2026-10-08
- 제품: QuickCut / Android 오프라인 경량 영상 편집기
- 범위: 구현 전 제품 기획. 이 문서는 개발 완료나 성능 달성을 의미하지 않음
- 반응형 UX 상세: [디자인 시스템](05_DESIGN_SYSTEM.md) · [적응형 레이아웃](06_ADAPTIVE_LAYOUT.md) · [화면 상세 설계](07_SCREEN_DETAIL.md)

## 1. 한 줄 정의

**갤러리에서 영상을 선택해 필요한 부분만 빠르게 편집하고, 복잡한 설정 없이 갤러리에 저장하는 Android 앱.**

편집 기능 수보다 **빠른 사용 흐름·내보내기 정확성·불필요한 재인코딩 최소화**를 우선한다.

## 2. 대상 사용자 및 핵심 시나리오

- 촬영한 영상의 시작과 끝을 잘라서 공유하려는 사용자
- 긴 영상에서 불필요한 부분을 제거하고 여러 장면을 연결하려는 사용자
- 기존 편집기에서 단순 작업에도 저장이 오래 걸린다고 느끼는 사용자
- 회원가입, 광고, 클라우드 업로드 없이 로컬 파일을 편집하려는 사용자

대표 흐름: **앱 실행 → 영상 1개 이상 선택 → 클립 편집 → 결과 미리보기 → 저장 → 갤러리 확인**

## 3. 확정할 제품 원칙

1. 회원가입·로그인·서버·클라우드 동기화·자체 DB는 초기 버전에 포함하지 않는다.
2. 가져온 원본 영상은 수정하거나 삭제하지 않는다.
3. 사용자가 **저장**을 눌러야 최종 파일을 생성한다. 편집 중 임시 프리뷰 생성은 최종 저장과 구분한다.
4. 가능한 한 재인코딩을 생략하지만 **영상 앞부분 노출, 부정확한 절단, 음성 싱크 오류를 허용하면서 속도를 높이지 않는다.**
5. 지원하지 않는 형식이나 작업은 명확한 오류와 대안을 보여준다.
6. 결과물에 워터마크를 넣지 않는다.
7. MVP의 편집 상태는 앱 실행 중에만 유지한다. 종료 후 복구·프로젝트 이어하기는 후속 기획 대상이다.
8. 기본 기능은 인터넷 없이 동작해야 한다. 광고·계정·분석 SDK는 MVP 범위에서 제외한다.

## 5. 기본 동작 요구사항

### 5.1 가져오기
- 기기 시스템의 영상 선택 UI 사용을 우선한다.
- 선택된 파일의 길이, 해상도, 회전 정보, 비디오·오디오 트랙 존재 여부를 확인한다.
- 열지 못하는 영상은 앱을 종료하지 않고 지원 불가 사유를 알린다.
- 파일 접근 권한이 더 이상 유효하지 않으면 재선택을 요청한다.

### 5.2 타임라인
- 기본은 **주 영상 1개 트랙**에 클립을 순서대로 배치한다. 영상 PIP·다중 영상 레이어는 MVP 제외.
- 클립별 시작·종료 범위와 배치 순서를 유지한다.
- 분할과 삭제 뒤에도 음성·화면의 타이밍이 어긋나지 않아야 한다.
- 0초 또는 실질적으로 길이가 없는 선택 구간은 저장할 수 없다.

### 5.3 내보내기
- 기본 컨테이너는 MP4. 파일 형식 변환은 초기 목표가 아니다.
- 자동 내보내기 경로 선택: **무재인코딩 가능 → 필요한 부분만 처리 가능 → 일반 인코딩** 순으로 검토.
- 편집 시점의 결과와 저장된 파일의 재생 시작점·종료점이 일치해야 한다.
- 저장 중 진행 상태와 취소 기능을 제공하고, 실패한 파일은 완성된 파일처럼 갤러리에 표시하지 않는다.
- 파일은 새 이름으로 생성한다. 원본은 보존한다.
- 성공 시 저장 위치와 파일 열기 안내를 제공한다.
- '원본 화질 보존' 표시는 실제 스트림 복사에 성공한 경우에만 사용한다.

## 6. 비기능 요구사항

| 분류 | 기준 |
| --- | --- |
| 개인정보 | 서버 전송·로그인 없음, 원본 보존, 저장 시 숨겨진 삭제 구간 데이터가 결과 파일에 포함되지 않게 설계 |
| 접근성 | 터치 영역 최소 48×48dp, 재생·자르기 컨트롤 읽기 가능한 레이블, 상태 텍스트 제공 |
| 사용성 | 주요 행동은 영상 선택·편집·저장에 집중, 불필요한 계층 메뉴 최소화 |
| 안정성 | 재생 실패·코덱 비호환·저장 공간 부족·취소·프로세스 종료 시 안전하게 오류 처리 |
| 성능 | 인코딩 생략이 가능한 작업은 일반 전체 인코딩 대비 유의미한 시간 절감 여부를 실측 |
| 파일 | 원본과 결과의 시간 범위·재생성·음성 동기화 확인, 저장 후 재열기 검사 |
| 네트워크 | 핵심 편집/저장 기능 오프라인 동작 |

## 7. 의도적으로 제외하는 범위

- 소셜 계정, 구독, 광고, 분석 SDK, 추천 피드
- 클라우드 업로드·서버 렌더링
- AI 자동 자막·얼굴 추적·자동 편집
- 실시간 다중 사용자 협업
- 복잡한 키프레임 애니메이션
- 데스크톱·iOS 동시 개발

## 8. 아직 검증이 필요한 결정

- MVP 최소 Android 버전과 지원 코덱 범위
- 4K, HEVC, HDR 소스의 편집/내보내기 지원 기준
- 다중 파일을 서로 다른 코덱·해상도로 합칠 때 기본 변환 정책
- Android 앱 백그라운드 전환 시 내보내기 지속 여부(초기에는 전경 작업 우선)
- 타임라인 썸네일 생성·캐시 범위 및 임시 파일 정리 기준

이 항목은 구현 전에 실기기 테스트로 결정한다. 확인되지 않은 성능이나 지원 범위를 보장하지 않는다.
