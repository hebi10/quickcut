# 05. QuickCut 디자인 시스템

- 상태: 디자인 기획안 v0.1
- 기준일: 2026-10-08
- 목적: 스마트폰·태블릿·폴더블에서 같은 조작 원칙을 유지하는 경량 영상 편집 UI
- 범위: 디자인 원칙과 수치 기준. 디자인 시안·실행 코드가 아닌 사전 설계 문서
- 관련: [적응형 레이아웃](06_ADAPTIVE_LAYOUT.md) · [화면 상세 설계](07_SCREEN_DETAIL.md)

## 1. 디자인 방향

**차분한 다크 UI, 영상 자체가 주인공, 조작은 최소화.**

- 기본 배경은 블랙·차콜·그레이.
- 프레임 미리보기에 가장 많은 시각적 비중을 할당.
- '영상 선택', '자르기', '분할', '삭제', '음소거', '저장' 기능을 명확하게 보이도록 유지.
- 저장은 주 행동으로 표시하되 화려한 색상이나 효과로 과장하지 않는다.
- 광고 배너, 가입 유도, 불필요한 정보 카드, 과도한 모달, 영구 사이드 내비게이션 금지.
- 과도한 그림자, 그라데이션, 둥근 카드, 장식용 애니메이션, 마우스 오버 효과를 사용하지 않는다.
- 기능 추가 시에도 '편집 집중' 원칙을 우선한다.

## 2. 디자인 토큰(초안)

### 2.1 색상

| 토큰 | 값 | 사용처 |
| --- | --- | --- |
| background | #0B0C0E | 앱 전체 배경 |
| surface | #151619 | 편집 도구·컨트롤 |
| surfaceElevated | #202126 | 팝업·작업 패널 |
| surfaceSelected | #303238 | 선택된 도구 또는 클립 배경 |
| divider | #36383E | 전체 폭 구분선 |
| textPrimary | #F4F4F5 | 주요 정보·버튼 |
| textSecondary | #B7BAC0 | 보조 설명·시간 레이블 |
| textMuted | #90949D | 부가 메타데이터(충분한 대비 확인) |
| accent | #EBECEF | 저장 강조·선택 테두리·재생 헤드(중립적 고명도) |
| previewBackground | #000000 | 영상 레터박스 |
| success | #69C693 | 저장 성공 등 상태에 한정 |
| warning | #E1B566 | 미지원·주의 상태에 한정 |
| error | #E37A7A | 저장 실패·삭제 위험 안내 |

**적용 원칙**

- 선택·활성 상태는 색상 **하나만**으로 구분하지 않고 테두리 두께, 체크 아이콘, 텍스트 변화 중 하나를 함께 제공.
- 상태 색상은 성공/경고/오류에만 사용하며 일반 기능 버튼은 무채색.
- 대비 목표: 일반 텍스트 4.5:1 이상, 큰 텍스트 및 주요 비문자 컨트롤 3:1 이상을 검증 기준으로 사용. 실제 구현 시 측정 필수.
- 비활성 컨트롤과 보조 텍스트는 동일하게 보이지 않도록 구분하고, 저대비로 의미 전달을 회피하지 않는다.

### 2.2 타이포그래피

| 역할 | 기준 | 사용 |
| --- | --- | --- |
| ScreenTitle | 20sp / SemiBold | 선택 화면, 완료 화면 |
| SectionTitle | 16sp / SemiBold | 도구 그룹, 내보내기 상태 |
| Body | 14sp / Regular | 안내 문구, 메뉴 |
| Button | 14sp / Medium | 저장/취소/삭제 |
| Timecode | 13sp / Medium, 고정폭 숫자 | 현재·전체 시간·트리밍 시간 |
| Caption | 12sp / Regular | 영상 메타 정보 |

- Android 기본 시스템 폰트를 우선하고, 별도 웹폰트·다운로드 폰트는 도입하지 않는다.
- 글꼴 확대 시 사용자 시스템 배율을 존중한다. 최대 200% 글꼴 확대에서 주요 행동이 잘리지 않도록 재배치·스크롤한다.
- 시간 코드는 동일 자릿수 폭으로 표시하여 탐색 시 숫자 떨림을 방지한다.

### 2.3 크기·간격

- 기본 간격 단계: 4 / 8 / 12 / 16 / 24 / 32dp.
- 스마트폰 좌우 여백: 12~16dp; 태블릿: 16~24dp.
- 상단 앱 바 기본 높이: 56dp, 높이 480dp 미만 압축 레이아웃: 약 48dp(실사용 영역 확보가 우선).
- 모든 클릭·드래그 가능한 버튼 및 아이콘 터치 영역: **최소 48×48dp**.
- 작은 자르기 핸들의 보이는 두께가 48dp보다 얇아도 **접근 가능한 실제 터치 영역**은 48dp 이상 보장.
- 주요 버튼 높이: 48dp 이상.
- 아이콘 표시 크기: 보통 20~24dp; 아이콘을 감싸는 터치 영역은 48dp 이상.
- 구분은 동일 두께 라인이나 영역 명암을 사용. 특정 한 면에만 별도 테두리 스타일을 주지 않는다.
- 버튼과 패널 모서리: 가능한 직각. 필요한 경우에도 0~4dp 수준만 허용. 그림자는 기본 0.

### 2.4 미리보기

- 가로 16:9, 세로 9:16, 정사각형 1:1 등 **원본 종횡비를 보존하는 Contain(Fit)**을 기본으로 한다.
- 미리보기 배경은 검정색, 남는 영역은 레터박스(검은 여백) 처리.
- 영상이 흐릿하게 늘어나거나 임의 크롭되지 않도록 한다.
- 비디오와 플레이 컨트롤의 오버레이는 콘텐츠를 가리지 않는 범위에서만 노출.
- 편집기 배경/패널은 다크로 유지하며 재생 중 원본 영상 색감을 변형하지 않는다.

## 3. 공통 컴포넌트

| 컴포넌트 | 세부 규격 | 상태 |
| --- | --- | --- |
| AppHeader | 뒤로가기(48dp), 'QuickCut' 또는 '편집', 저장(높이 48dp) | 기본/편집 중/저장 불가 |
| PreviewSurface | 원본 종횡비 보존, 중앙 정렬 | 준비/재생/일시정지/불러오기 실패 |
| PlaybackBar | 재생/일시정지, 현재/전체 시간, 시킹 | 재생 가능/로딩 |
| ClipTimeline | 클립 썸네일 띠, 재생 헤드, 가로 스크롤 | 비선택/선택/재정렬 |
| TrimHandles | 시작/끝 제어 핸들, 구간 시간 레이블 | 포커스/드래그/활성 |
| ToolDock | 자르기/분할/삭제/순서/음소거 | 사용 가능/비활성/선택 |
| ExportStatus | 저장 진행 정보·취소 | 대기/진행/완료/실패/취소 |
| SystemDialog | 작업 포기·저장 취소 등 파괴적 선택 확인 | 기본/확인/취소 |
| InlineNotice | 오류 및 복구 행동을 같은 화면에서 제공 | 일반/주의/오류 |

### 아이콘 및 레이블

- 아이콘은 하나의 라인 아이콘 세트로 통일.
- 스마트폰 기본 모드에서는 **아이콘+레이블** 우선, 높이 제한 시 레이블을 생략할 수 있으나 접근성 이름을 반드시 유지.
- 위험한 삭제/포기 기능은 명확한 텍스트와 확인 단계(필요한 경우)를 제공.
- 저장 버튼은 어디서든 같은 명칭 **'저장'** 사용.
- 타임라인에서 '분할'은 재생 헤드 기준, '자르기'는 시작/끝 범위 선택을 의미한다.

## 4. 상태·피드백

1. **로딩**: 영상 분석/썸네일 생성/내보내기 준비를 구분하여 상태 문구 제공.
2. **선택**: 현재 선택된 클립의 배경·외곽선·클립명 표기를 함께 사용.
3. **편집**: 되돌릴 수 있는 편집과 확정된 파일 저장을 명확히 구분.
4. **저장**: 실제 진행률을 얻을 수 있을 때만 백분율 표시; 그 외 '준비 중' 사용.
5. **오류**: 실패 이유, 계속 작업 또는 재시도 행동을 안내.
6. **완료**: 파일이 정상적으로 저장된 경우에만 완료 표시.
7. **음소거**: 토글 활성 상태를 아이콘+레이블(예: '음소거 켜짐')로 표시.

전환 장식 애니메이션은 사용하지 않으며, 상태 전환의 즉각적인 피드백만 허용.

## 5. 접근성

- 최소 터치 대상 48×48dp. Android 공식 Compose 권장과 일치.
- 모든 아이콘 버튼과 타임라인의 주요 조작에 TalkBack 레이블/역할/상태 부여.
- 드래그만으로 수행해야 하는 필수 작업이 없어야 한다. 자르기는 시작/끝 시간 조정 UI도 제공하도록 설계(세부는 화면 문서).
- 타임라인 정렬은 드래그 외에 클립 이동 버튼 등 대체 동작 검토.
- 글자 확대, 고대비 설정, 시스템 탐색 모드(제스처/3버튼), 키보드 포커스를 검증한다.
- 상태가 색상에만 의존하지 않도록 한다.
- 자막/시간 입력에서 키보드 표시 시 편집 도구와 저장 버튼이 가려지지 않도록 한다.
- 영상의 깜빡임·빠른 모션은 원본 콘텐츠 영역에만 존재할 수 있으나 앱 UI에는 불필요한 깜빡임을 사용하지 않는다.

## 6. 디자인에서 제외

- 앱 로고/일러스트/마스코트 생성
- 홈 피드, 카테고리 탭, 로그인 화면
- 광고 슬롯·유료 구독 배너
- 스마트폰 UI를 태블릿으로 단순 비율 확대하는 방식
- 실제 Compose 컴포넌트 구현
