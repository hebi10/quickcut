- 기준: 2026-10-08
- 대상: QuickCut 0.2.0 개발판
- **Android 15 에뮬레이터 검증 완료:** JVM 테스트 33개, Android 계측 테스트 12개 모두 통과
- Android 계측 결과: [GitHub Actions](https://github.com/hebi10/quickcut/actions/runs/37758868868)
- **실제 30개 이상 동영상 일괄 처리 및 다양한 기종의 실기기 검증은 미완료**

## 사용자 흐름

`시작 → 템플릿 · 일괄 편집 → 규칙 작성/불러오기 → 여러 영상 선택 → 예상 길이/날짜 확인 → 일괄 편집 시작 → 개별 저장 결과 → (선택) 원본 처리 승인`

## 구현 내용

| 항목 | 동작 |
| --- | --- |
| 로컬 템플릿 | 최대 30개, 이름/앞뒤 시간/추출 방식/음소거를 SharedPreferences(JSON)에 저장 |
| 구간 처리 | 앞뒤 제거 / 처음 N초 / 마지막 N초 / 앞뒤 연결 |
| 원본 선택 | 여러 개 선택, 중복 URI 제외, 최대 250개 |
| 큐 | Media3 Transformer 순차 실행, 영상별 진행률·상태 표시 |
| 오류 격리 | 실패한 입력만 실패 표시, 나머지는 가능한 경우 계속 |
| 짧은 영상 | 구간이 겹치거나 남는 장면이 0.1초 미만이면 건너뜀 |
| 저장 | 입력별 별도 MP4, 원본 이름을 기반으로 새 파일명 생성 |
| 저장 날짜 | 현재 날짜 또는 원본 촬영 날짜(없으면 파일 수정 날짜) |
| 원본 처리 | 기본 유지, 완료 뒤 성공 원본만 사용자 및 Android 승인 요청 |
| 재시도 | 성공 파일은 그대로 두고 실패·건너뜀만 재시도 |
| 중지 | 현재 내보내기를 취소하고 저장된 결과는 유지 |
| 종료 복구 | 미구현: 앱이 프로세스 종료되면 대기 작업 상태는 사라짐 |

## 날짜 처리 원칙

**현재 날짜:** MP4 컨테이너 생성·수정 시각을 새 저장 시각으로 기록하며 파일은 새 MediaStore 항목으로 등록합니다.

**원본 날짜:** 원본 `MediaStore.DATE_TAKEN` → 영상 메타데이터 → DocumentProvider 수정 시각 → MediaStore 수정 시각 순으로 확인합니다. MP4 컨테이너의 `Mp4TimestampData`에 원본 시각을 기록하고, 가능한 기기에서는 파일 수정 시각도 변경합니다. 저장 후 결과의 날짜를 다시 읽어 확인하며, 적용되지 않으면 해당 결과 파일 등록을 되돌리고 오류로 표시합니다.

- MediaStore `DATE_TAKEN` / `DATE_MODIFIED`는 읽기 전용 인덱스입니다. 직접 쓰기를 시도하지 않습니다.
- 실제 촬영 메타데이터가 없고 수정 시각만 있을 수 있습니다. 이 경우 선택 화면에 **날짜 출처**를 표시합니다.
- 메타데이터가 없는 경우 임의 현재 시각을 **원본 날짜로 표시하지 않습니다**.
- Android 갤러리 앱의 날짜 정렬·원본/수정 시각 표시 정책은 제조사마다 다를 수 있습니다.
- 여러 영상을 하나로 합치는 단일 편집은 **첫 원본의 날짜**를 기준으로 합니다. 일괄 편집은 **개별 원본마다** 날짜를 지정합니다.
