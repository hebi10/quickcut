# QuickCut UI 리파인먼트 (2026-11-04)

## 범위

기존 Pocket Cut Studio 브랜드의 잉크그린/민트 색상과 Kotlin + Jetpack Compose 구조를 유지하며, 화면의 정보 계층과 컨트롤 정렬만 정리했습니다.

- 홈: 편집 모드 섹션, 장식 최소화, 시작 일러스트
- 빠른 자르기: 원본/결과 시간 요약 패널, 56dp 높이의 ± 버튼과 입력창
- 상세 편집: 빈 상태 이미지와 영상 추가 CTA, 미리보기 모서리 정리
- 일괄 편집: 영상 선택 → 템플릿 → 자르기 → 저장 순서, 입력 높이 통일
- 저장 설정: 원본 처리·날짜 선택 구분, 영구 삭제 경고
- 고속 저장 선택: 원본에서 지정한 구간 유지(기본 강조) vs 추천 위치 고속 저장(선택)의 차이를 명시
- 미리보기 오류/저장 완료: 상태별 일러스트와 복구/후속 행동을 표시

## 리소스

| 리소스 | 표시 화면 | 설명 |
| --- | --- | --- |
| `quickcut_new_edit.webp` | 홈, 상세 편집 빈 화면 | 새 영상 추가 시각 안내 |
| `quickcut_preview_error.webp` | 미리보기 복구 | 저장과 분리된 미리보기 오류 안내 |
| `quickcut_saved.webp` | 저장 완료 | 결과 영상 저장 확인 |

세 리소스는 사용자가 앞서 생성한 투명 배경 원본 PNG에서 리사이징·WebP 최적화한 에셋입니다. 기존 `quickcut_mark.webp` 브랜드 마크를 유지합니다.

## 기능 경계

미디어 파이프라인, 저장 계획 선택 로직, 원본 삭제 승인, 설정 지속성, 네트워크·권한, 작업 복구와 테스트 태그는 변경하지 않았습니다. 이미지와 레이아웃만 수정했으며 Play Store 배포는 포함하지 않습니다.

## 검증

CI에서 `android.yml` 빌드, unit test, lint와 APK/AAB 생성 결과를 확인해야 합니다. 실제 모바일/폴더블 에뮬레이터에서 글자 확대, IME 노출, 편집 타임라인, 48dp 이상 터치 영역을 재확인합니다.
