# 12. 단일 MP4 고속 자르기 및 검증

- 적용 버전: Android 0.2.1
- 목적: 긴 영상에서 몇 초만 제거해도 전체를 다시 인코딩하는 시간을 줄인다.
- 범위: 단일 클립의 구간 자르기(앞/뒤 삭제 포함), 전체 음소거, 현재 날짜 저장.
- 원칙: **자른 장면이 출력 데이터에 남지 않아야 하며, 지원 조건이 맞지 않으면 기존 Media3 Transformer로 복귀한다.**

## 저장 방식

1. `FastMp4Trimmer.prepare()`가 `MediaExtractor`로 트랙과 자르기 경계를 검사한다.
2. H.264/HEVC(SDR) + 지원되는 오디오(AAC), 단일 비디오 트랙, 원본의 안전한 키프레임 시작점인 경우 고속 경로를 선택한다.
3. `GalleryWriter.saveDirect()`가 `IS_PENDING=1`로 갤러리 항목을 생성하고 파일 디스크립터를 연다.
4. `MediaExtractor`와 `MediaMuxer`가 **압축 샘플을 직접 복사**한다. 디코딩·재인코딩은 하지 않는다.
5. 출력 길이(허용 오차 250ms)와 오디오 존재 여부를 검증한 뒤 `IS_PENDING=0`으로 공개한다.
6. 빠른 경로를 사용할 수 없거나 검증에 실패하면 임시 결과물을 삭제하고 Media3 Transformer로 다시 시도한다. 취소는 재시도하지 않는다.

이 경로는 전체 영상을 메모리에 올리지 않으며, 출력 MP4를 갤러리에 직접 기록하므로 **임시 MP4 생성 + 갤러리 재복사**를 피한다. 다만 출력 영상 길이만큼 파일 데이터는 계속 기록해야 하므로 처리 시간이 0이 되지는 않는다.

## 안전 조건과 폴백

- 시작점은 지정 시각 이상에 위치한 키프레임이어야 하며, 시작 시각 차이가 50ms 이하여야 한다.
- 지정 시각 **이전**의 키프레임을 출력에 포함시키지 않는다. MP4 edit list로 데이터를 숨기는 방식도 사용하지 않는다.
- 복수 클립, HDR/지원되지 않는 코덱, 비정상 트랙, 큰 키프레임 간격, 비정상/재정렬 타임스탬프, 암호화·부분 샘플은 기존 엔진에 위임한다.
- `원본 날짜 유지`는 생성·수정일 검증을 유지하기 위해 기존 Media3 경로를 사용한다. 따라서 대용량 영상에서 속도 개선 효과가 없을 수 있다.
- 원본 영상은 변경하지 않는다. 사용자 선택에 따른 원본 삭제·휴지통 이동은 **갤러리 저장 성공 이후** 기존 승인 절차를 따른다.
- 고속 저장이 도중에 실패하면 미완성 `IS_PENDING` 결과물을 삭제한다. 취소도 동일하게 정리한다.
- 현재 버전은 모든 원본에서 고속 저장을 보장하지 않으며, 키프레임 간격 때문에 전체 재인코딩이 실행될 수 있다.

## 진단 로그

`adb logcat -s QuickCutExport:I`에서 아래 항목을 확인한다.

- `method=fast_remux`: 압축 스트림 복사 완료. `elapsedMs`는 갤러리 기록·검증 시간을 포함한다.
- `method=media3`: Transformer 사용. `optimization`, `videoProcess`, `audioProcess`로 최적화 및 재인코딩 여부 확인.
- `Fast remux unavailable`: 고속 경로 도중 오류가 발생하여 안전한 Media3 경로로 재시도했다.

`FastMp4Trimmer.prepare()`에서 지원되지 않는 구간으로 판단한 경우는 로그 없이 바로 Media3로 넘어갈 수 있다.

## 테스트

- JVM: 키프레임 정확 일치, 다음 프레임 허용 범위, 삭제 구간 노출 방지, 먼 키프레임 폴백, 너무 짧은 구간, 첫 프레임 처리.
- Android 계측: H.264/AAC 샘플에서 고속 경로 준비 검사, 직접 갤러리 저장 및 영상·오디오 길이 검증.
- 기존 단일/다중/음소거/일괄 저장 계측 테스트로 회귀 검증.

### 필수 실기기 확인

1. 1시간짜리 H.264/AAC 1080p MP4에서 앞 4초 삭제. `method=fast_remux` 여부·경과시간·결과 길이 확인.
2. 키프레임 간격이 다른 영상으로 동일 작업. `method=media3` 폴백 이후 길이·영상 품질 확인.
3. 뒤 4초 삭제, 앞뒤 동시 삭제, 음소거, 2개 클립 연결, 4K/HEVC/HDR 테스트.
4. `원본 날짜 유지` 옵션에서 원본 날짜가 보존되는지 확인.
5. 원본 유지/휴지통/영구 삭제와 취소·저장 공간 부족 시 미완성 파일 및 원본 보호 확인.
6. 반복 실행 5회 이상의 중앙값으로 기존 버전과 속도 비교. 특히 긴 영상에서 실제 처리 경로를 함께 기록한다.

**테스트 상태 주의:** 에뮬레이터의 짧은 H.264/AAC 영상만으로 1시간짜리 실기기 성능을 검증할 수 없다.
