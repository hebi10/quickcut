# 0.4.2 일괄 고속 저장

## 변경 범위

- 일괄 분석에서 파일별 다음 키프레임 제안을 유지한다. 추가 키프레임 조정 제안은 승인 없이 적용하지 않으며, 기존 고속 저장의 최대 50ms 시작 이동 허용 범위는 유지한다.
- `위치 조정 후 고속 저장`을 선택하면 파일명, 기존/변경 시작 위치, 추가 삭제 길이, 저장/건너뜀 개수를 모두 확인한다.
- 승인한 위치는 해당 실행에만 사용한다. 마지막 사용 설정과 템플릿은 바꾸지 않으며 중단·재시도·재실행 시 새로 분석한다.
- 분석 이후 영상 목록이나 설정이 바뀌면 이전 확인 결과로 시작하지 않는다.
- 변경된 출력 길이를 작업 기록에 저장하여 중단 후 출력 검증에서도 실제 구간을 사용한다.
- 끝부분을 자르지 않는 AVC/HEVC SDR 영상은 고속 저장 조건을 충족하면 B프레임도 원래 압축 샘플 순서와 시각을 유지하고 실제 파일 끝까지 복사한다.
- 고속 저장 제외 사유를 시작 키프레임, 끝부분 자르기와 B프레임, 코덱, HDR, 추가 트랙, 파일 읽기 등으로 구분한다.

## 사용 예

앞 3초 삭제 요청에서 다음 키프레임이 4초라면 `3초 → 4초 · 1초 추가 삭제`를 표시한다.
변경을 승인한 경우에만 4초부터 고속 복사하며, 원래 3초 기준은 정밀 저장으로 유지할 수 있다.
이미 고속 저장 가능한 파일은 원래 구간으로 함께 저장하고, 여전히 지원하지 않는 파일은 사전에 표시한 뒤 건너뛴다.

## 유지되는 제한

다음 키프레임 제안은 10초 이내이며 변경 후 최소 0.1초가 남아야 한다.
HDR, 지원하지 않는 오디오·영상 코덱, 추가 트랙, B프레임 영상의 중간 종료 등은 정밀 저장이 필요할 수 있다.
선택한 키프레임 뒤에 그보다 이른 시각의 영상 프레임이 나오는 open-GOP는 고속 저장에서 제외한다.
정밀 저장의 Media3 트림 최적화는 기존대로 시도하지만 장치·영상 호환성에 따라 전체 재인코딩할 수 있다.
고속 저장 모드에서 동의 없이 재인코딩으로 전환하지 않는다. 삭제 구간이 파일 안에 남는 MP4 edit-list 우회도 사용하지 않는다.

## 배포

앱 버전 `0.4.2`, versionCode `7`. 0.4.1 배포 APK와 같은 고정 키로 서명한다.
서명 키와 비밀번호는 저장소에 포함하지 않는다.
