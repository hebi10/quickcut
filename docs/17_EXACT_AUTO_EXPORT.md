# 0.4.3 정확한 위치 자동 저장

## 목표와 범위

요청한 시작·끝 시간을 임의로 키프레임에 맞춰 옮기지 않고, 원본 복사와 부분 인코딩 최적화를 가능한 경우에 사용한다. 모든 영상·기기에서 고속 저장을 보장하는 기능은 아니다.

Media3의 부분 인코딩 최적화는 기존 정밀 저장에도 이미 켜져 있었다. 이번 변경은 정확한 구간을 지키는 조건을 추가하고 실제 처리 결과를 표시하는 보완이다.

## 처리 순서

1. 요청 시작과 안전한 키프레임이 정확히 맞으면 직접 복사를 시도한다. 기존 최대 50ms 시작 이동 허용을 제거한다.
2. 직접 복사를 사용할 수 없고 자동 저장을 선택했다면, 시작 시각이 바뀌지 않는 조건에서 Media3 부분 인코딩 최적화를 시도한다.
3. 최적화가 불가능하면 원래 요청 구간을 유지하는 일반 인코딩으로 처리한다. 기기가 해당 형식을 처리하지 못하면 오류로 알린다.

Media3 자체도 키프레임이 가까우면 시작 시각을 옮기는 최적화 분기를 사용한다. 같은 Media3 MP4 메타데이터를 분석하여 이 분기를 피할 수 있을 때만 부분 최적화를 허용한다. 판단할 수 없거나 재생 시각이 뒤섞인 경우에는 보수적으로 일반 처리로 진행한다.

`위치 조정 후 고속 저장`은 별도 선택으로 남는다. 이 선택에서만 사용자가 확인한 추가 삭제 길이를 적용한다.

## 정확도의 의미

요청 구간의 시작·끝 설정을 그대로 유지한다. 영상 프레임이나 압축 오디오 패킷이 없는 임의의 밀리초에 새 프레임을 만들어 주는 의미는 아니다. 출력의 첫·마지막 프레임과 오디오 타이밍은 원본의 프레임률·샘플 단위 제약을 받는다.

## 결과 표시

출력이 검증되고 갤러리에 등록된 뒤 실제 처리 결과를 원본 복사, 일부 구간 인코딩, 전체 영상 인코딩, 소리 인코딩 또는 확인 불가로 표시한다. 확인되지 않은 이전 작업의 처리 방식을 추정하지 않는다. 결과 표시나 기록 오류로 이미 저장된 파일을 재인코딩하거나 삭제하지 않는다.

## 남는 제한

부분 인코딩 결과와 원본의 코덱 초기화 정보가 호환되지 않으면 전체 처리가 필요하다. 코덱·HDR·추가 트랙·손상 또는 암호화된 파일과 기기 디코더/인코더의 제약도 남는다. 삭제 구간을 파일에 남기는 MP4 edit-list 방식으로 우회하지 않는다.

## 검증과 배포

2초에서 빨강에서 파랑으로 바뀌는 영상의 1.95초 자르기를 검사하여 다음 키프레임으로 잘못 이동한 결과를 구분한다. 일괄 저장의 원래 구간·완료 길이·처리 결과·복구 기록도 확인한다. 실행 결과는 PR 검증 항목에 기록한다.

앱 버전 0.4.3, versionCode 8. 이전 0.4.1·0.4.2와 동일한 고정 인증서를 사용한다.
