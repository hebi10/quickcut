# 0.4.8 고속 처리 지원 확장

사용자가 승인한 오디오 형식·H.265 연결·10비트 및 HDR 지원 확장이다.
정확한 자르기 좌표를 유지하고 완전한 중간 GOP는 복사한다. 키프레임과 맞지
않는 경계만 처리하므로 짧은 구간에 복사할 GOP가 없으면 일반 저장이 필요하다.

- AAC 외 MP3·AC-3·E-AC-3·Opus·FLAC·ALAC·지원 PCM을 AAC로 처리한다.
  1~8채널을 유지하며, 영상 전체를 복사했다면 결과에 소리 처리로 표시한다.
- HEVC Main10의 SDR·HDR10(PQ)·HLG를 지원한다. 정적 HDR 정보와 색상 정보는
  복사 구간뿐 아니라 인코딩한 앞뒤 경계에도 유지해야 한다.
- H.265 IDR의 앞 프레임 폐기 지시는 새 연결 지점에서 호환성이 확인될 때만
  보정한다. 원본 파일, 첫 출력 장면, 그대로 유지되는 구간 내부는 변경하지 않는다.
- 일반 저장이 필요한 경우 기존 사유 코드를 유지하며 넓어진 지원 범위에 맞게
  안내 문구를 수정한다. Dolby Vision·HDR10+·12비트 등은 이번 지원 범위 밖이다.
- 재생 순서가 다른 프레임을 MP4로 다시 담을 때 마지막 장면의 표시 길이가
  반 프레임 짧아지지 않도록 검증된 원본 프레임 간격을 유지한다. 프레임의
  재생·디코딩 시각이나 자르기 좌표는 변경하지 않는다.

검증은 복사된 압축 데이터, 실제 디코딩 프레임 수와 연결 지점의 장면,
역순·반복 구간의 채널별 소리, HDR 정보와 독립적인 경계 디코딩을 확인한다.
Android 검사는 실제 저장 방식·전체 디코딩·소리·색상 정보를 검사한다.
API 35 에뮬레이터에는 Main10 디코더가 없으므로 이 형식은 Android 네이티브
엔진의 실제 출력 파일을 꺼내 독립 FFmpeg 디코더로 전체 프레임·색상·HDR을
검증한다. Main10 디코더가 있는 기기에서는 갤러리 저장과 MediaCodec 재생도
검사한다. 에뮬레이터 검사만으로 실제 기기의 Main10 재생을 검증했다고 보지 않는다.
제품의 시작·끝 프레임 검증은 유지하므로 Main10 저장에는 해당 기기의 디코더
지원이 필요하다.
새 버전 배포는 이 검사와 기존 취소·복구·원본 날짜·회전 검사를 통과한 후 진행한다.

3시간 원본의 개별 오류 원인은 아직 재현하지 못했다. 이번 확장만으로 해당 오류가
해결되었다고 보장하지 않으며, 실패 화면의 오류와 고속 처리 제한 사유로 추가 진단한다.
