# 0.4.9 고속 저장 추천 위치

요청한 위치를 유지하는 자동 저장과, 더 잘라내고 영상 복사를 사용하는 고속 저장을 선택할 수 있다.

## 사용자 확인

- 저장 방식 선택 화면에 변경되는 각 구간의 원본 기준 요청·추천 시간을 `시:분:초.밀리초`로 표시한다.
- 시작·끝에서 각각 추가 삭제되는 길이와 총 추가 삭제 길이를 표시한다. 키프레임 간격이 길면 수 초 이상 차이가 날 수 있다.
- `추천 위치로 고속 저장`을 눌러야 편집 구간에 반영하고 저장한다. `정확한 위치로 자동 저장`과 `취소`는 요청 위치를 유지한다.
- 저장 전 편집이 달라지면 이전 추천을 적용하지 않는다. 추천은 해당 편집에만 적용하며 빠른 자르기의 공통 설정을 바꾸지 않는다.
- 저장 취소·실패 후 편집 화면에서 실행 취소로 위치 조정을 되돌릴 수 있다. 고속 저장이 실패하면 현재 선택한 구간의 정확한 저장을 다시 선택할 수 있다.
- 일괄 저장은 파일마다 조정 내용과 고속 저장에서 건너뛸 파일을 표시한다. `전체 자동 저장`은 기존 설정대로 모든 저장 가능한 파일을 처리한다.
- 긴 영상의 추천 분석은 취소할 수 있다. 실패 후 정확한 저장을 선택하는 화면에서는 추천 분석을 반복하지 않는다.

## 범위와 검증

보존할 구간의 시작은 다음 안전 지점으로, 끝은 이전 안전 지점으로만 이동한다. 중간 삭제도 삭제 범위가 넓어지는 방향이다. 삭제하려던 장면을 다시 포함하거나, 구간 전체를 없애거나, 클립 순서·음소거 상태를 바꾸지 않는다. 최소 0.1초를 남긴다.

한 구간의 직접 복사를 우선 확인한다. 직접 복사가 어려우면 기존 네이티브 엔진이 같은 원본의 여러 구간까지 검사한다. 닫힌 GOP와 실제 패킷, IDR 경계, 타임스탬프, 메타데이터를 검증하고 모든 영상 구간을 복사할 수 있는 경우에만 추천한다. 현재 편집 모델로 정확히 나타낼 수 없는 밀리초 미만 경계는 임의로 반올림하지 않는다.

고속 전용 저장은 실행 직전에 다시 검사하며 영상 재인코딩으로 자동 전환하지 않는다. 네이티브 경로에서 소리는 AAC로 변환될 수 있다. 형식·구간 구성·파일 읽기 제한 때문에 안전한 추천을 찾지 못하면 정확한 위치 저장을 사용한다. 모든 영상의 고속 처리를 보장하지 않는다.

정책·표시 단위 검사, 동의·정확한 저장·취소 UI 검사, B프레임 끝 지점 추천, 중간 삭제의 Android 실제 저장, 네이티브 출력 프레임 해시 비교와 영상 재인코딩 차단 검사를 포함한다. 실제 기기와 사용자의 3시간 원본에 대한 확인은 별도다.
