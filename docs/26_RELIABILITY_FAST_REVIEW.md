# 0.4.10 저장 복구·추천 위치 보완

## 변경 사항

- 단일 저장도 출력 URI와 예상 길이·소리·날짜를 쓰기 전에 원자적으로 기록합니다. 앱이 중단되면 소유권과 상태를 확인해 미완성 출력을 정리하거나 검증한 완료 결과를 복구합니다. 확인할 수 없으면 기록을 유지하고 중복 저장을 막습니다. 원본 삭제 동의는 복구하지 않습니다.
- 날짜 유지용 `quickcut_date_UUID.mp4`도 앱 소유 임시 파일 정리 대상에 포함합니다. 다른 파일은 삭제하지 않습니다.
- 네이티브 전체 원본 분석은 파일의 장치·inode·크기·변경 시각을 검사하여 재사용합니다. FD 번호나 경로 문자열만으로 원본을 판단하지 않습니다. 최대 4개/16MiB 캐시이며 실패·취소·검사 중 변경된 원본은 저장하지 않습니다. 각 저장 계획과 실제 출력 검증은 계속 수행합니다.
- 추천 시각을 마이크로초로 유지합니다. 예를 들어 `3.336667초`를 화면용 밀리초로 반올림하여 저장하지 않습니다. 안전한 키프레임 후보 중 안쪽 방향으로만 찾으며, 최소 구간 길이·영상 복사 가능 여부를 확인합니다. 검색 상한을 넘거나 안전성을 확인하지 못하면 추천하지 않습니다.
- 요청·추천 경계의 가까운 화면을 비교하고 남길 시작/끝과 구간 연결부를 최대 3초 재생할 수 있습니다. 기기 디코더가 지원하지 않는 미리보기는 안내만 표시하며 저장 동의로 취급하지 않습니다. 재생 화면은 기기 디코더 출력이므로 HDR 최종 색감 검증을 대신하지 않습니다.
- 일괄 저장 확인 화면에서 파일별 현재 위치 유지·추천 위치 사용·제외를 고릅니다. 현재 위치는 자동 처리, 추천 위치는 영상 재인코딩 금지 정책을 사용합니다. 파일·설정 변경이나 재시도는 다시 검토합니다.
- 저장 진행 화면에 준비·분석·복사/처리·결과 검사·갤러리 저장/등록 단계를 표시합니다. 원본 분석 진행률도 표시합니다. 서로 다른 단계의 퍼센트는 전체 완료 예상 시간이 아닙니다.
- 최근 저장 한 건의 단계, 앱/기기, 첫 원본 형식·크기·길이, 저장 길이, 시작 시 여유 공간, 처리 사유와 오류 종류를 기기 안에 보관합니다. 원본 URI·경로·파일명·내용·원시 오류 메시지는 기록하지 않습니다. 사용자가 진단 복사를 누르는 경우에만 클립보드에 복사하며 자동 전송하지 않습니다. 일괄에서는 마지막 처리 한 건의 기록입니다.

## 검증 범위

새 회귀 검사는 미완성/공개 출력의 복구, 타 앱 파일·권한 불확실성, 원자적 기록 실패, 정밀 시간 복원·동의, 파일별 선택, 미리보기 실패, 실제 영상 패킷 복사, 캐시의 원본 변경·FD 재사용·취소·상한을 포함합니다. 기존 AAC/MP3/서라운드, HEVC, Main10 SDR/HDR10/HLG, 취소/갤러리/날짜/회전 검사는 유지합니다.

네이티브 장시간 검사는 기존 저해상도 시간값 검사에 더해 **3시간 1920×1080·10fps·48kHz 스테레오 AAC 합성 영상의 끝부분 복사**를 검사합니다. 반복 합성 영상이며 실제 고비트레이트 3시간 촬영본의 처리 부하와 손상을 대변하지 않습니다. 네이티브 출력은 독립 FFmpeg 디코더로 확인하고, Android 계측 검사는 Android 15 에뮬레이터에서 실행합니다.

CI 실행과 결과 수는 [Actions](../../actions)에서 해당 배포 소스와 함께 확인합니다. 서명 APK는 기존 고정 인증서로 만들고 versionCode 14→15 업데이트 시 앱 데이터 보존을 검사합니다.

## 실기기에서 남은 확인

1. 기존 앱 위에 업데이트하고 마지막 설정·템플릿·편집 복구를 확인합니다.
2. 실제 3시간 원본과 1080p/4K, 가변 프레임레이트, HDR 영상에서 앞·중간·끝을 잘라 저장합니다. 추천 추가 삭제량을 확인하고 허용할 때만 적용합니다.
3. 요청/추천 미리보기와 출력 첫·끝 장면, 연결부의 화면·소리 동기, 채널·회전·HDR 밝기를 대조합니다.
4. 원본은 유지한 채 화면 끄기·앱 전환·저장 중 프로세스 종료 후 재실행을 확인합니다. 완료 중복 파일 또는 미완성 파일이 남으면 최근 저장 진단을 복사합니다.
5. 저장 공간 부족·권한 회수 뒤 오류 단계와 재시도 가능 여부를 확인합니다. 원본 삭제 시스템 승인은 별도로 검증합니다.

Fold8 실기기와 사용자가 보고한 3시간 원본은 이번 환경에서 접근할 수 없습니다. 해당 원본 오류가 해결됐다고 확인하지 않았습니다. 코덱·프레임 구조·추가 트랙·손상·기기 디코더 등의 조건 때문에 모든 영상의 고속 편집을 보장하지는 않습니다.
