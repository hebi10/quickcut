# 대용량 원본 로컬 벤치마크와 실기기 QA

합성 원본의 긴 타임스탬프 검증, 실제 원본의 로컬 성능 측정, Android 기기 검증을 별도로 기록한다. 합성 3시간 파일의 성공은 사용자의 원본이나 Fold8에서 성공했다는 증거가 아니다. 원본은 업로드하지 않는다.

## 호스트 벤치마크

`docs/20_NATIVE_SMART_CUT.md`의 고정 버전 도구와 네이티브 의존성을 먼저 준비한다. `scripts/build-native-smartcut.sh --host-tests`를 실행한 Linux 빌드 환경에서는 다음처럼 **같은 고정 의존성**을 사용한다. 아래는 기본 캐시 경로이며 `QUICKCUT_NATIVE_CACHE`를 사용했다면 경로를 맞춘다.

```bash
export CARGO_TARGET_DIR="$PWD/build/native-smartcut/cargo-target"
export PKG_CONFIG_PATH="$PWD/build/native-smartcut/prefix/host/lib/pkgconfig"
export PKG_CONFIG_LIBDIR="$PKG_CONFIG_PATH"
export PKG_CONFIG_SYSROOT_DIR=''
export PKG_CONFIG_ALL_STATIC=1 FFMPEG_STATIC=1
# LIBCLANG_PATH와 BINDGEN_EXTRA_CLANG_ARGS는 네이티브 빌드 환경과 동일하게 유지한다.
python3 scripts/benchmark-large-source.py
```

기본 입력은 1920×1080, 10fps, closed-GOP AVC, 무음/비디오 전용 8초 seed를 재인코딩 없이 반복한 정확히 3시간 파일이다. 파일은 64 MiB 이하로 제한된다. 이 입력은 긴 타임스탬프와 많은 패킷을 저렴하게 재현하며, 높은 비트레이트·복잡한 장면·오디오·열 부하를 대신하지 않는다. 큰 파일 I/O를 측정하려면 명시적 스트레스 프로필을 사용한다. 다음은 약120MB 예상의 1080p30/16Mbps,60초 파일이다. 실행 전에 예상 크기와 필요한 여유 공간을 표시하고 공간이 부족하면 생성을 거절한다. 이 프로필은64MiB 제한을 적용하지 않는다.

```bash
python3 scripts/benchmark-large-source.py --profile stress1080p --duration-seconds 60 --runs 3
# 약21.6GB 예상: 충분한 로컬 공간이 있을 때만 명시적으로 선택한다.
python3 scripts/benchmark-large-source.py --profile stress1080p --duration-seconds 10800 --runs 3
```

스트레스 입력도8초의 testsrc2 seed를 CBR로 인코딩한 뒤 복사 반복한다. 원래 촬영된3시간의 장면 변화/열 부하/오디오 구조를 재현하지 않는다. CBR 패딩과 컨테이너 오버헤드 때문에 실제 크기는 예상치와 다를 수 있다. 검사 전에 디스크 캐시를 비우거나 시스템 설정을 바꾸지 않는다. 실제 I/O 성능은 원본 복사본으로 추가 측정한다.

```bash
python3 scripts/benchmark-large-source.py --source /local/private/source.mp4 \
  --start-us 10791000000 --end-us 10798000000 --runs 3
```

`--source`는 로컬 일반 파일만 받는다. 기본 결과는 git에서 제외되는 `build/large-source-benchmark/run-*/`에 남는다. 이름, 경로, URI, 영상 내용, 원시 오류, 해시는 `summary.json`에 기록하지 않는다. 다만 합성 입력과 내보낸 영상 자체는 해당 로컬 작업 폴더에 남으므로, 필요한 검증 후 그 실행 폴더만 직접 지운다. 원본이 지원되지 않으면 실패하며 정확 모드로 자동 전환하지 않는다.

각 실행은 새로운 프로세스에서 최초 추천, 같은 프로세스의 재추천, 추천 구간 복사 저장을 순서대로 측정한다. `initial_recommendation_ms`, `repeated_recommendation_ms`, `copy_export_ms`는 벽시계 시간이다. 재스캔 여부는 분석 시작 progress(0) 관찰값이다. 이는 내부 단계별 CPU 프로파일이 아니며 OS 디스크 캐시는 초기화하지 않는다. 원본 불변 확인 해싱이 측정 전에 전체 입력을 읽으므로 첫 실행의 디스크 캐시도 데워질 수 있다. 앱 분석 캐시의 최초 비용과 물리 저장소의 cold-cache 비용을 구분한다. 컴파일·합성 입력 준비·원본 불변 확인 해싱·독립 디코딩 시간은 저장 시간에 포함하지 않는다. `preparation_ms`, `independent_decode_ms`는 별도로 기록한다. 영상 재인코딩 패킷은 0이어야 하며, 저장 구간은 추천된 안전 경계에 맞춰 바뀔 수 있다.

보고서는 성공한 모든 출력의 전체 영상/오디오를 별도 FFmpeg로 디코딩하고 길이 오차를 100ms 이내로 검사한다. 출력 픽셀·음질·HDR 메타데이터의 동일성을 보증하는 검사는 아니므로 관련 네이티브/Android 회귀 검사를 함께 실행한다. 실행 전후 원본 SHA-256을 메모리에서 비교하되 보고서에는 `source_unchanged`만 남긴다. `--prepare-only --duration-seconds 24`는 도구와 작은 fixture 생성만 확인하며 엔진 통과로 표시하지 않는다.

## 실기기 재현 기록

실제 원본, 지원되는 USB 연결 기기, 검증할 최종 APK가 있어야 한다. 모델·Android API·앱 버전/커밋·남은 저장 공간·입력 코덱/해상도/프레임률/오디오 형식·길이·바이트 수를 로컬 표에 기록한다. 소유자 이름, 파일명, URI, 계정, 원본 내용은 공유 보고서에서 뺀다. 실제 Fold8 또는 해당 사용자 원본이 없다면 해당 항목은 **미검증**으로 둔다.

1. 최소 API 29 기기와 최신 지원 API 기기, 실제 Fold8에서 각각 확인한다. 에뮬레이터 크기 변경은 폴더블 접기/펼치기·제조사 코덱 검증을 대체하지 않는다.
2. 배포판과 동일 서명/업데이트 경로를 확인한다. 다른 debug 키 설치는 기존 앱을 업데이트하지 못할 수 있다. 기존 앱 삭제/데이터 초기화로 우회하지 않는다.
3. 시스템 파일 선택기로 원본을 선택한다. 원본의 바이트 수와 수정 시각을 로컬에서 기록한다. 상세 편집에서 재생/일시정지 직후 분할, 구간 선택 변경 직후 분할, 화면 회전·접기/펼치기 직후 분할을 반복한다. 새 미리보기 위치와 분할 시간이 맞고 이전 구성의 콜백이 반영되지 않아야 한다.
4. 원본 처음·중간·끝 근처에서 같은 약 7초 범위에 대해 빠른 추천과 저장을 각각 3회 측정한다. 최초 분석과 반복 추천을 구분하고 앱 재시작 여부를 기록한다. 최근 저장/실패 진단의 단계별 시간을 함께 확인한다. 단일 평균으로 최초 스캔 비용을 숨기지 않는다.
5. 원본이 all-intra AVC인 경우 빠른 추천/복사 저장이 가능해야 한다. 일반 AVC closed-GOP, B-frame AVC, HEVC/Main10 및 오디오 조합은 기존 안전 제한대로 처리되어야 한다. 빠른 모드 불가 시 이유가 표시되고, 재인코딩에는 명시적 동의가 필요하다.
6. 저장 중 홈 이동·화면 잠금 후 완료/알림을 확인한다. 별도 실행에서 저장 중 프로세스를 종료하고 복구한다. 시스템 제공자가 잠시 응답하지 않거나 출력 조회가 불확실한 경우 미확인 기록을 성공/없음으로 확정하거나 중복 저장하지 않아야 한다. 저용량은 시험용 저장소/복사본으로 재현한다.
7. 일괄 작업 일부 실패 후 다른 작업을 성공시킨다. 실패 진단이 남고 결과 작업의 진단 ID가 맞는지 확인한다. 진단에 원본 경로/URI/파일명/원시 오류/영상 내용이 없어야 한다. 관련 없는 사용자 데이터를 고의로 손상시키지 않는다.
8. 출력의 시작·중간·끝을 Android 플레이어와 독립 도구에서 재생한다. 짧은 검정 화면·프레임 손실·A/V 불일치·HDR/회전 변화가 없어야 한다. 원본 바이트 수/수정 시각을 다시 비교한다. 필요하면 기기 내 해시도 비교한다. 원본 삭제를 누르지 않는다.
9. TalkBack, 큰 글꼴, 가로 화면, 접힘/펼침에서 선택 그룹의 역할/선택 상태/레이블을 확인한다. 선택된 항목이 읽히고 포커스가 저장 동작을 방해하지 않아야 한다.

| 환경 | 원본 분류 | 최초 추천 3회(ms) | 반복 추천 3회(ms) | 저장 3회(ms) | 독립 재생/원본 보호 | 결과 |
| --- | --- | --- | --- | --- | --- | --- |
| 호스트 합성 3시간 | AVC 1080p/10fps/비디오 전용 | 측정값 | 측정값 | 측정값 | 확인 내용 | 미실행/통과/실패 |
| 실기기/API | 실제 로컬 원본 특성 | 측정값 | 측정값 | 측정값 | 확인 내용 | 미검증/통과/실패 |
| Fold8/API | 실제 로컬 원본 특성 | 측정값 | 측정값 | 측정값 | 확인 내용 | 미검증/통과/실패 |
