# QuickCut 모달·상세 화면 디자인 검증

기준: 2026-11-05 · 0.4.19 · Jetpack Compose

## 디자인 적용

- `CutDialogShape = RoundedCornerShape(4.dp)`를 모달 외곽에만 사용합니다.
- 기존 `CutShape = 14.dp` 및 `CutPanelShape = 20.dp`는 일반 편집 도구·패널에 유지해 화면 구조를 변경하지 않습니다.
- 버튼의 최소 터치 영역 48dp, 주요 입력창 56dp, 길이가 긴 모달 콘텐츠의 최대 표시 높이 420dp와 스크롤을 우선합니다.
- 설명을 제목·본문·주의 문구로 구분하고, 원본 영구 삭제만 오류 색상을 사용합니다.
- 저장 선택 시 요청 구간 보존을 기본 행동으로 강조하고, 고속 추천은 실제 잘리는 시점 변경을 안내합니다.
- 일괄 저장 확인·템플릿·진단·개인정보·라이선스·복구 화면은 상태 및 기존 동작을 유지합니다.

## 화면별 캡처

`DialogDesignInstrumentedTest`가 저장 설정, 원본 영구 삭제 동의, 정확한 위치 자동 저장, 저장 중 취소 가능·불가, 이전 편집 복구, 진단 기록, 라이선스, 개인정보처리방침 모달을 캡처합니다.
기존 `EditorDesignInstrumentedTest` 및 `android-dialog-geometry-check.sh`가 홈, 빠른·상세 편집, 일괄 저장 확인, 템플릿 관리의 실제 화면·모달 배치를 확인합니다.

에뮬레이터 검증 경로: GitHub Actions `Android build` / `Android emulator smoke`. 실제 캡처는 `quickcut-design-review`가 포함된 에뮬레이터 artifact에서 확인합니다.

## 보존

미디어 편집·저장 엔진, 키프레임, 템플릿 상태, 원본 삭제 동의, 로컬 파일 처리, 권한, 인증서·배포 자동화는 변경하지 않습니다.
원본 이미지의 새로운 아이콘으로 런처를 임의 교체하지 않고, 기존 마크·테마 아이콘의 일관성을 보존합니다. 홈에는 이미 연결된 필름스트립 일러스트를 사용합니다.
