# QuickCut Purple · 실제 구현 범위 (0.4.20)

참고 디자인: 사용자가 제공한 QuickCut 보라색 화면별 가이드 2종.

## 디자인 기준
- 배경: `#0B0810` / 표면: `#191324` / 상위 패널: `#292039`
- 주요 행동: `#8B5CF6`; 비활성·선택 패널: `#382252`; 보조 보라: `#C4B5FD`
- 텍스트: `#F8F6FF` / 보조 `#CFC6DF`
- Material Symbols 기반 가위·재생 로고, 런처는 단색 심볼·보라 배경, 홈 필름스트립은 기존 로컬 이미지를 보라색으로 틴트 처리
- 제어 버튼 최소 48dp, 시간 입력 56dp, 모달 외곽 16dp, 카드 20dp

## 화면
- 홈: 브랜딩, 진입 방식, 이전 편집 이어서 진행(저장된 경우), 마지막 설정·진단·정책
- 빠른 자르기: 비디오 미리보기, 선택 구간, ± 버튼, 음소거, 저장 설정 및 저장
- 상세 편집: 재생·타임라인·자르기·분할·순서·음소거·영상 저장
- 일괄 편집: 다중 영상 선택, 편집 방식/시간/프리셋, 저장·확인
- 내보내기: 저장 방식 분석, 요청 위치와 추천 위치 비교, 원본 처리 승인, 저장 진행/완료
- 모달: 기본 색상과 보라색 상태 아이콘을 공통 적용. 기존 확인 및 취소 동작 유지

## 실제 기능과 다른 시안 항목
제공된 시안에는 온보딩, 계정 기반 프로젝트 목록, 앱 내 이미지 그리드 갤러리, 자막, 화면 회전, 프레임 속도·해상도·비트레이트 변경 등 화면이 포함되어 있습니다. 
이 중 현재 QuickCut 소스에 없는 기능은 가짜 버튼으로 만들지 않았습니다. 실제 동작 변경과 권한·데이터 모델 설계가 필요한 기능은 별도 개발 범위입니다.
영상 선택은 계속 Android 시스템 파일 선택기를 사용합니다.

## 검증
GitHub Actions `Android build`(Unit + Lint + APK/AAB), `Android emulator smoke`(API 29, 35, 36, 실제 캡처)를 실행합니다.
Play 게시 대상은 내부 테스트입니다. 게시 완료는 Google Play API 릴리스 상태 `PUBLISHED`가 확인된 경우에만 기록합니다.
