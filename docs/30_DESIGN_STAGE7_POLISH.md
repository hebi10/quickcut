# QuickCut 디자인 수정 7단계 · 화면 정밀 수정

## 반영
- 홈: 모드 제목 간결화, 개수·도구 설명은 보조 문구로 분리
- 일괄: 영상 선택·자르기 제목 간결화, 자동 복원 설명 분리, 결과 요약 대비 개선
- 공통 선택 메뉴: 분류와 현재값을 분리하고 드롭다운 아이콘을 우측 정렬; 기존 TalkBack·선택·비활성 동작 유지
- 상세 편집: 선택 도구의 작은 글자·아이콘 색을 라벤더로 조정
- 모달: 긴 제목 폭 확보, 삭제·취소·종료 경고색 적용, 취소·계속 저장 48dp
- 저장 완료: 안내 문구와 긴 처리 방식 요약 정렬 개선

## 회귀 검증
- 320dp/160% 글꼴의 홈 모드 제목 1줄 표시
- 긴 모달 제목 미절단 및 취소·계속 저장 최소 터치 높이
- 선택 메뉴의 선택값·비활성 상태·동작
- PR 빌드/단위 테스트/Lint 및 API29·35·36 에뮬레이터 검증 후 병합

## 기능/배포 범위
영상 편집·저장 엔진, 원본 처리 승인, 템플릿, 데이터, 권한, 서명키, 버전, Play 트랙 변경 없음. 기존 앱에서 미지원하는 온보딩, 영구 프로젝트, 자체 갤러리, 자막·회전·속도·해상도 설정을 가짜 UI로 추가하지 않음.
