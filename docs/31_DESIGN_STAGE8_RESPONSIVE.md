# QuickCut 디자인 수정 8단계 · 반응형 최종 점검

## 범위
- 휴대폰 320dp/360dp, 가로 모드, 폴더블 840dp, 태블릿
- 일반 글꼴, 160%, 200% 글꼴
- 홈 모드 카드·빠른 자르기·상세 편집 타임라인·일괄 편집 시간 입력·선택 메뉴·저장 옵션·모달

## 변경 사항
- 화면 너비가 충분하더라도 확대된 글꼴에서 2열 UI의 각 열이 과도하게 좁아지는 현상을 방지하기 위해 홈, 일괄 편집, 상세 편집의 `fontScale` 인식 기준을 보완
- 빠른 자르기는 가로 화면에서도 확대 글꼴로 인한 편집 입력창 폭 부족 시 세로 배치 우선
- 7단계 PR 테스트의 잘못된 import 두 건 수정
- 320dp·200% 홈/일괄 편집, 폴더블·200% 홈, 저장 모달·200% 시험 및 실제 스크린샷 보관
- 새 화면 증거의 파일명 검증 규칙을 기존 자동 수집 방식에 맞춰 확장

## 검증 및 배포
- Android build(컴파일·단위 테스트·Lint·APK/AAB)와 Android 10/15/16 에뮬레이터 smoke 검사
- 캡처 아티팩트의 화면 잘림·레이아웃·버튼 터치 영역 확인
- 편집/저장 기능·데이터·원본 삭제 승인·서명키·앱 버전·배포 트랙 미변경
- 성공한 PR만 main 병합. 내부 테스트 게시 상태는 사용자의 명시 요청대로 별도 확인하지 않음
