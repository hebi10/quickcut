# QuickCut 디자인 10단계 · 보조 화면·상태·접근성 마무리

## 경계
기존 디자인 기획은 1~9단계 완료 상태입니다. 사용자의 추가 요청으로 10단계를 보조 정보·상태·작은 화면 접근성 품질 개선 작업으로 신규 편성합니다.

## 수정 대상
- 홈: 글꼴 160% 이상에서 '마지막 사용 설정' 제목과 '설정 변경' 조작을 세로로 분리하여 좁은 창에서 겹침 방지. 기존 설정·표시값 유지.
- 단일 저장 분석: 글꼴 160% 이상에서 진행 표시와 장문 안내를 세로로 분리하고 설명을 스크롤 가능하게 처리. 기존 분석 취소·퍼센트 표시 유지.
- 작업 진단: '기록 목록으로', '진단 복사' 최소 터치 높이 48dp 명시.
- 일괄 저장: 저장 중단/계속 저장, 분석 취소, 알림 확인, 템플릿 직접 설정 버튼 최소 높이 48dp·기존 모서리 스타일 통일.

## 검증
- 기존 StudioDesignInstrumentedTest의 320dp/200%에서 설정 제목 잘림 방지 확인.
- DialogDesignInstrumentedTest의 200% 저장 분석 진행/취소 노출 및 48dp 터치 영역, 실제 캡처 수집.
- 기존 단위 테스트·Lint·APK/AAB 빌드 및 API29/35/36 에뮬레이터 계측 검증.
- API별 전체 성공 전 main 병합 금지. Google Play 내부 테스트 게시 완료 여부는 사용자 요청대로 확인하지 않음.

편집·인코딩·파일 선택·원본 삭제 승인·백그라운드 실행·템플릿 데이터·권한·앱 버전·서명키·배포 트랙/워크플로 변경 없음. 미구현 온보딩·영구 프로젝트 목록·자체 갤러리·자막/해상도/음악 UI 임의 추가 없음.
