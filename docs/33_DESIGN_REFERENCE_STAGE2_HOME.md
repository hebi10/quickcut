# QuickCut 수정시안 재구현 · 2단계 (스플래시·온보딩·홈)

## 기준
- 우선 시안: Google Drive `QuickCut_보라색_리디자인_수정시안.png` (2026-11-05)
- 색상·크기 토큰: 1단계 `QuickCutTheme.kt`
- 영상 처리, 데이터 영속화 및 저장 엔진은 수정하지 않는다.

## 화면
1. 시작 스플래시: Android 12 이상 OS 스플래시 아이콘과 다크 창 배경을 유지하고 앱 창 색상을 수정시안 배경으로 통일했다. Android 10/11은 OS 시작 창 동작이 달라 이미지와 1:1 시각 일치 여부를 기기별로 검수한다.
2. 온보딩: 최초 실행에만 표시되는 3페이지 안내, 인디케이터, '다음/시작하기' 조작. 로컬 `quickcut_onboarding/complete` 플래그는 마지막 시작 버튼 이후에만 저장한다. 페이지 상태는 회전 시 유지한다.
3. 홈: '영상 편집 시작하기', 이전 편집 이어서 진행(복구 가능한 경우), 편집 도구 진입, 하단 홈/프로젝트/도구/설정 내비게이션.
4. 프로젝트 탭은 현재 저장·복원 가능한 마지막 편집만 보여 준다. 시안의 여러 프로젝트 기록·썸네일 영구 목록은 기능과 저장 구조가 필요한 3단계로 이관했다. 가짜 예시 프로젝트를 표시하지 않는다.
5. 설정 탭은 기존 마지막 사용 설정, 진단 기록, 개인정보 보호, 라이선스 기능을 재사용한다.

## 검증
- 홈 계측 검증: 폭 320dp, 200% 글꼴, 840dp 폴더블 및 탭/도구 콜백.
- 테마 계측 검증: 수정시안 컬러값 및 텍스트 대비.
- Android build(Lint, unit, APK/AAB)와 API 29/35/36 에뮬레이터 검증 성공 전 병합 금지.
- UI 원본 픽셀 비교, 갤러리·프로젝트 목록, 전체 시안 일치는 추후 단계로 남는다.
