# QuickCut 수정시안 3단계 — 프로젝트 목록 및 영상 선택

## 구현
- `ProjectStore`: 각 프로젝트의 타임라인/클립/선택 위치/빠른 편집 모드를 별도 SharedPreferences 스냅샷으로 저장한다. 마지막 자동복구 기록과 독립적으로 관리한다.
- 프로젝트 목록: 제목, 최근 수정 날짜, 클립 수, 첫 클립 프레임 썸네일, 다시 열기 및 삭제 확인.
- 편집기 상단 '프로젝트 저장' 버튼: 새 프로젝트 저장과 기존 프로젝트 재저장.
- 프로젝트 열기: `EditorViewModel.loadSavedSession`의 원본 메타데이터 재검증 경로를 재사용한다. 접근 불가능한 원본은 실패 처리하고 기존 파일을 삭제하지 않는다.
- 영상 갤러리: 사용자가 Android Photo Picker에서 승인한 영상 목록만 앱 내부 그리드/썸네일로 보여 주고 복수 선택 후 편집에 전달한다. 시스템 전체 갤러리 열람 권한을 요청하지 않는다. 앨범별 전체 인덱스 검색은 지원하지 않는다.

## 안전성·제한
- 프로젝트 삭제는 JSON 편집 스냅샷만 삭제한다. 원본 영상은 삭제하지 않는다.
- 시스템 Photo Picker에서 선택한 URI 접근이 나중에 끊길 수 있다. 복구 시 원본 접근을 검증한다.
- 기존 마지막 편집 복구 기능을 유지한다.
- 사용자 자료를 임의로 클라우드에 업로드하지 않는다.
- 3단계에서는 앱 자체 미디어 라이브러리의 전체 스캔, 파일 이동, 자체 앨범 인덱스는 구현하지 않는다.
- 모든 화면의 원본 픽셀 일치 여부는 실제 기기 캡처 비교 전까지 확정할 수 없다.

## 검증
