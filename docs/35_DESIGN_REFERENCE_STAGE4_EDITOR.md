# QuickCut 수정시안 재구현 4단계 — 빠른 자르기·상세 편집

## 기준 이미지
Google Drive `02_디자인_이미지/QuickCut_보라색_리디자인_수정시안.png`의 5번 편집 화면과 `QuickCut_보라색_디자인가이드_상세화면.png`. 시안은 영상 미리보기 → 재생/시간 표시 → 타임라인 → 도구 순서를 강조한다.

## 반영
- 빠른 자르기: 헤더를 공통 다크 Surface로 통일하고, 원본 길이·남길 구간·결과 영상 길이를 구분해 가독성을 개선한다.
- 원본 영상 썸네일·RangeSlider로 남길 구간을 드래그 조절할 수 있다. 최소 100ms 구간 제약을 적용하고, 기존 정밀 시간 입력과 ± 조작, 음소거, 저장 옵션, 고속 저장 분석 및 상세 편집 전환은 그대로 유지한다.
- 상세 편집: 상단 타이포그래피·버튼을 공통 토큰으로 정리하고 도구 그룹과 타임라인 패널의 레이어를 통일한다.
- 타임라인: 패널 외곽선, 제목과 전체 시간 계층을 정리한다. 드래그/선택/정렬/줌과 사용자 입력 처리 코드는 유지한다.
- 기존 상세 편집 계측 테스트가 캡처하는 `editor_design_quick_trim`, `editor_design_detailed` 스크린샷을 시각 검수 증거로 사용한다.

## 의도적으로 미구현
- 시안의 자막, 속도, 회전, 화면 밝기/대비/채도 등은 현재 영상 처리기와 프로젝트 데이터 모델에 없는 기능이다. 화면에 가짜 조작 버튼을 추가하지 않는다.
- 도구 아이콘의 실제 기능이 기존 '분할·삭제·순서·음소거'와 다르므로 기존 실제 기능 이름을 유지한다.
- 픽셀 단위 일치는 원본 1080x1920 화면과 동일한 밀도·해상도의 에뮬레이터 캡처를 나란히 검증하기 전에는 완료로 간주하지 않는다.
