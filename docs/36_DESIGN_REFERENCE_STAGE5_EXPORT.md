# QuickCut 수정시안 디자인 5단계 — 내보내기 및 저장 완료

## 기준
- Google Drive 2026-11-05 보라색 수정시안 중 내보내기 설정/진행/완료 화면
- 기존 저장 엔진, 원본 삭제 승인, 고속 저장 판단, 저장 날짜, 오류 복구 정책 유지

## 코드 반영
1. 저장 설정 다이얼로그: 지원하는 저장 기본값(원본 해상도/프레임 속도, 기기 갤러리 저장)을 명확히 안내한다. 날짜·원본 처리 선택은 기존 기능을 유지한다.
2. 진행 화면: 공통 Surface 패널, 보라색 원형 진행 표시, 상태별 텍스트와 실제 단계 진행률. 진행률 미확인/최종화 시 수치를 추정하지 않는다.
3. 저장 완료: 썸네일, 완료/처리 정보, 갤러리 열기, Android 공유 선택기, 새 영상 편집 기능을 제공한다.
4. 공유는 실제 완료 영상 URI에 한해서만 사용하며, 시스템 읽기 권한과 기존 오류 안내를 유지한다.
5. Android 계측 검증: 저장 설정 정보, 진행 퍼센트, 완료 단계에서 취소 비노출.

## 기능 및 디자인 차이
- 시안의 해상도/프레임 속도/비트레이트 변경 드롭다운은 현재 내보내기 엔진에 연결된 선택 옵션이 없다. 실제로 지원하지 않는 편집 설정을 가짜 동작으로 추가하지 않는다.
- 저장 위치는 기존 MediaStore 갤러리 정책을 유지한다. 사용자가 임의 폴더를 고르는 UI는 새 저장소 권한 정책과 기능 설계가 필요하다.
- 완료 영상은 현재 정적 썸네일이며, '갤러리에서 열기'에서 실제 영상 앱으로 재생한다.
- 원본 디자인과 픽셀 단위 일치는 에뮬레이터 스크린샷 대조가 끝나기 전까지 완료로 표시하지 않는다.
