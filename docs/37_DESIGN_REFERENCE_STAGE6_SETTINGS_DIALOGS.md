# QuickCut 수정시안 재구현 6단계 — 설정·모달·예외 상태

## 기준
- Google Drive 최신 보라색 수정시안 (2026-11-05), 상세 화면 및 화면 흐름 가이드
- 공통 디자인 시스템: `QuickCutTheme.kt`, `CutColors`, `CutSpacing`, `CutSizes`
- 기존 사용자 설정, 원본 처리 승인, 편집 세션 복구, 백그라운드 작업, 저장 엔진 유지

## 반영
- `CutInfoSection`: 기본 정보, 주의 및 오류 패널을 공통 Material Surface·패딩·타이포그래피로 통일, 그림자 없음
- 마지막 사용 설정: 새 영상 기본값과 원본 보호 원칙을 정보 패널로 표시
- 이전 편집 복원: 실패 사유·원본 재연결 안내와 기존 복구 동작을 구분
- 저장 방식/원본 영구 삭제/저장 취소: 위험 안내를 상태에 맞는 색과 레이블로 구분
- 편집 종료/클립 삭제: 결과 파일과 원본 삭제를 혼동하지 않도록 안내
- 홈 및 프로젝트 빈 상태: 공통 정보 컴포넌트 적용
- 모달 제목 아이콘 크기 공통 토큰 적용, 진단/라이선스의 기존 동작 유지

## 검증
- 기존 DialogDesignInstrumentedTest 및 UI 회귀 테스트
- Android build (Unit, Lint, APK/AAB) + API 29/35/36 emulator smoke
- 큰 글꼴/좁은 화면에서 본문 스크롤 및 버튼 접근 확인
- 기존 원본·파일 삭제 동작과 권한 정책은 변경하지 않았음
