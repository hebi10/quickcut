### 시각 검수
- 온보딩·홈·프로젝트 빈 화면: `Stage7ReferenceScreensInstrumentedTest` 캡처
- 빠른/상세 편집·일괄/저장 관련 모달: 기존 `EditorDesignInstrumentedTest`, `DialogDesignInstrumentedTest` 캡처

- 기존 1080×2400 캡처와 1080×1920 시안을 픽셀 일치 완료라고 주장하지 않는다.
- 테스트에서 캡처 산출물 생성·보존 실패는 누락으로 처리한다.

## 3. 자동 배포 검증
- `main`의 병합 SHA 자체에서 `Android build`와 `Android emulator smoke`가 모두 통과하는지 확인한다.
- GitHub Actions `Google Play test release`는 정확한 main SHA에 대한 2종 CI 성공 게이트를 적용한다.
- 내부 테스트 대상 자동 배포를 유지한다. 비공개 테스트로 자동 변경하지 않는다.
- `Google Play test release` 성공은 실제 제출/업로드 단계와 결과 로그를 확인하기 전에는 Play 게시 성공으로 표시하지 않는다.
- 릴리스의 실제 `versionCode`는 기존 자동 할당 정책을 유지한다. 비밀키·서비스 계정 정보는 출력/수정하지 않는다.
