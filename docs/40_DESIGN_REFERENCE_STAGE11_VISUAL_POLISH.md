## 기능·안전 경계

- 원본 디자인에 나온 비디오 썸네일은 **실제 템플릿 모델에서 제공하지 않는 데이터**이므로 가짜 썸네일을 표시하지 않는다.
- 자막 추가·속도 조절·회전·해상도/FPS 선택·전체 갤러리 무단 탐색은 이 단계에서 임의로 추가하지 않는다.
- 실제 소스 영상, 인코더, 원본 휴지통·삭제 승인, 템플릿 스키마·저장/선택/삭제, 앱 버전·서명, GitHub Actions 및 Google Play 배포 트랙은 변경하지 않는다.
- Android 시스템 스플래시의 별도 배경 아트는 시스템 제한에 따라 기존 스플래시 아이콘/색상을 유지한다.
- 동일 화면비·폰트/콘텐츠의 실기기 픽셀 대조와 템플릿에 실제 썸네일을 부여하는 기능은 별도 과제다.

## 검증과 병합 조건

1. 11단계 PR 최신 HEAD에서 Android build(JVM 테스트·Lint·APK/AAB) 완료·성공.
2. 같은 HEAD의 Android emulator smoke API29/35/36 각 작업 모두 완료·성공 및 실제 렌더링 아티팩트 생성.
3. 화면 아티팩트에서 온보딩 아트워크·빠른 자르기 요약 순서·템플릿 관리 레이아웃 검토.
4. 1~3 성공 시에만 `main` 병합, 병합 SHA의 2종 CI를 다시 확인.
5. 기존 자동 Google Play internal 배포만 사용하며 워크플로 성공과 실제 Play 게시를 구분한다.

검증과 배포의 최신 상태는 GitHub Actions 및 PR 기록을 최우선 근거로 판단한다.
