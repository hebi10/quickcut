# QuickCut 디자인 12단계 — 상세 편집 미리보기·타임라인·도구 배치 정밀 보정

## 근거 및 목표

- 원본 디자인: Google Drive `QuickCut_보라색_리디자인_수정시안.png`의 편집 화면 및 `QuickCut_보라색_디자인가이드_상세화면.png`.
- 보정 전 Android 실제 화면: 11단계 `main` 커밋 `95f2b872c286fe6c97fb3bb5d8535d29ba5b3c0f`, API35의 `editor_design_detailed.png`.
- 실제 화면은 작은 화면의 상단 헤더가 혼잡하고 5개 편집 도구 중 끝쪽 도구가 가로 화면 밖으로 밀렸다. 타임라인 정보는 두 줄에 반복되며 선택 클립 카드가 큰 편이다.
- 원본 시안의 재생 위치·썸네일 타임라인·하단 도구 순서에 가깝게 조정하되 기존 지원 기능을 제거하지 않는다.

## 변경

1. **헤더**: 500dp 미만 또는 큰 글꼴의 좁은 창에서는 뒤로·제목·저장 버튼을 첫 줄에, 실행 취소·다시 실행·영상 추가를 두 번째 줄에 배치한다. 큰 화면은 기존 한 줄 조작을 유지한다.
2. **미리보기**: 영상 위 중앙 재생 버튼은 기존 미리보기 재생 동작만 호출한다. 하단 재생 버튼·시간·위치 슬라이더는 그대로 유지하고 시간 대비를 강화한다.
3. **타임라인**: 보통 글꼴에서 제목과 전체 길이를 한 줄로 표시하고, 큰 글꼴에서는 두 줄을 유지한다. 썸네일 높이(86→78dp), 헤더·목록 간격을 줄이되 확대·선택·핸들 드래그·길게 눌러 순서 변경 동작은 그대로 보존한다.
4. **도구**: 기본 너비 320dp 이상·글꼴 150% 미만의 스마트폰에서는 자르기·분할·삭제·순서·음소거를 한 행에 균등 배치한다. 더욱 좁거나 확대 글꼴인 경우 기존 가로 스크롤을 유지한다. 도구 제목·원본 소리 상태를 한 행으로 합치고 각 도구는 최소 74dp 높이를 확보한다.
5. **검증**: API29/35/36 기존 회귀 테스트에 추가로 보통 화면의 모든 도구 표시와 320dp 화면의 5개 도구·타임라인·미리보기 중앙 버튼 접근성 검사를 추가한다.

## 변경하지 않는 기능

- 편집 모델, 원본 영상 접근·승인, 인코더, 자르기 정확도·분할·삭제·순서·음소거·실행 취소·다시 실행 동작
- 저장 결과·미디어 파일, 앱 버전, 서명, CI 파이프라인, Google Play 내부 테스트 자동 배포 설정
- 원본 시안에만 있는 자막·속도·회전·크롭·해상도/FPS 선택을 가짜 버튼으로 추가하지 않음
