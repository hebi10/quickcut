# QuickCut 17단계 — 오디오 볼륨·페이드 구현/검증

작성: 2026-11-08 · 대상: Android QuickCut 0.4.20 · 기준: main 13단계 안정 버전  
원본 기획: https://docs.google.com/document/d/1fTi_fx0g6CF6SwpRKjrlYdbK9Pp9oAqmSg6To4GkhfI/edit

## 범위 및 기존 기능 보호
- 상세 편집 도구에 **오디오** 추가. 기존 자르기·분할·삭제·순서·음소거 등 유지.
- 클립별 원본 볼륨 **0–100%**(기본 100%), 페이드 인·아웃 0초(기본). 한 클립에 미리보기를 듣고 적용·취소.
- 오디오 트랙이 없거나 원본 클립이 음소거된 경우 처리 기능 비활성화 및 이유 안내. 기존 음소거는 원본 트랙을 꺼 둔 상태로 유지; 볼륨 0%는 트랙을 제거하지 않고 무음으로 인코딩.
- 사용자 지정 오디오 편집이 없는 프로젝트는 현재 **고속 원본 복사**와 원본 유지/삭제 승인/날짜/진단/저장 공간/복구 정책을 그대로 사용한다.
- 사용자 지정 오디오 편집이 있으면 fast-only 저장을 중단하고 명시적 재인코딩 동의를 받는다. 사용자 동의 없이 음성 프레임을 변환하지 않는다.
- 기존 프로젝트 JSON에 오디오 필드를 선택적으로 추가한다. 이전 저장 데이터에는 100%·0초/0초 기본값을 적용한다.
- 오디오 설정은 기존 EditHistory/EditorSessionStore/ProjectStore를 통한 undo/redo, 세션 복원·프로젝트 저장과 함께 이동한다.

## 오디오 엔진 및 화면
- `AudioAdjustment.kt`: 불변 설정 데이터, 페이드 길이 클램프, 샘플 위치의 gain envelope. 입력 0–100%/음수 페이드 불가.
- `ClipAudioEffects.kt`: Media3 `GainProcessor` + `GainProvider`로 0–1 범위 샘플 레벨 오디오 gain 적용, 새로운 프로세서 인스턴스를 클립별로 생성.
- `CompositionFactory`: 원본 오디오를 변경한 클립에만 효과를 연결하고, 편집 미리보기와 MP4 저장에서 같은 규칙을 사용.
- `ExportPlanner`, `VideoExporter`: 오디오 변경 시 네이티브 빠른 복사 우회, 편집하지 않은 클립은 현행 고속 경로 유지.
- `AudioEditorScreen.kt`: 영상 재생 및 소리 미리보기, 실제 PCM에서 추출한 소리 파형, 음량 슬라이더, 0.5초 단위 페이드 인/아웃, 기본값 초기화, 하단 고정 취소/적용.
- `AudioWaveformReader.kt`: 오프라인 한정·읽기 전용 PCM 추출, 영상이 길면 **앞부분 최대 15초만** 표시하고 명확하게 한정 범위를 안내. 디코딩 불가 시 없는 파형을 꾸며 내지 않고 설명.
- 설정 변경은 250ms 안정화 후 미리보기 효과 갱신. 디코딩 부하/플레이백 오류를 사용자 안내로 노출.
