## 반영 범위

1. 온보딩: 기존 3페이지·완료 시점·저장 정책 유지. 회색 중립 프레임/단색 도구 아이콘으로 장식 이미지를 교체. 본문 스크롤과 하단 고정 CTA를 분리해 큰 글꼴 대응.
2. 홈: 단일 편집 시작 CTA → 실제 최근 프로젝트 최대 3개 → 복원 가능한 작업 → 도구 진입 순서로 재구성. 기존 빈 상태에는 실제 저장 프로젝트가 없음을 안내.
3. 프로젝트: 제목/클립 수/수정일을 개별 정보 계층으로 표시. 썸네일을 축소해 좁은 화면의 제목 공간 확보. 전체 프로젝트 열기와 별도 삭제 확인 유지.
4. 도구: 빠른 자르기/상세 편집/일괄 편집/여러 구간 추출을 동일한 단색 카드로 정렬. 기존 갤러리 진입과 기능 콜백 유지.
5. 설정: 화면 테마, 편집 기본값, 저장 날짜, 진단 및 정보 영역을 구분. 시스템/라이트/다크 설정과 기존 영속화·팝업 동작 유지.
6. 사용하지 않던 보라색 그라데이션·장식 이미지용 홈 함수 제거.
