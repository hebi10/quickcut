선행 PR: #55 (UI-03-A, Draft). 이 단계는 UI-03-A 브랜치를 기준으로 구성하고, 선행 PR의 검증·병합 이전에는 `main`에 합치지 않습니다.

적용 범위: Kotlin/Jetpack Compose의 가독성, 화면 레이아웃, 정보 위계만 변경. Media3/스마트 컷, 비디오 시간 산술, 프로젝트 스냅샷, 원본 처리 동의, 런처, 배포/서명/Play 트랙은 불변.

## 화면별 적용

### 빠른 자르기
- 영상 프리뷰에 명확한 '영상 미리보기' 소제목과 기존 검은 프레임 유지.
- 구간 슬라이더의 시간 표시를 '시작/끝'과 고정폭 숫자로 구분.
- 자르기 구간 → 앞·뒤 삭제 시간 → 입력 오류 → 원본/남길 구간/결과 영상 → 소리 → 저장 옵션 → 하단 '영상 저장' 순서로 정리.
- 기존 초 단위 입력, ±1초 보정, 최소 0.1초 유효성, 원본 설정 저장·재인코딩 동의 콜백 유지.
- 결과 요약 테스트 태그 `ui04a-quick-result-summary` 추가.

### 상세 편집
- 미리보기 컨트롤의 현재 시각과 전체 시간을 고정폭 숫자로 분리. 큰 글꼴/좁은 창에서 수직 배치.
- 가로/세로 도구 영역에서 실제 선택 클립 번호·길이와 음소거 상태를 표시.
- '자르기 범위' 타이틀 및 시작/종료 시간 레이블을 동일한 정보 체계로 정리.
- 기존 실행 취소·다시 실행, 재생, 트림, 분할, 삭제, 순서 변경, 크롭, 오디오, 텍스트, 영상 저장 콜백 유지.
- 선택 클립 태그 `ui04a-selected-clip`, 플레이백 시각 태그 `editor-playback-time` 유지.

### 타임라인
- 개별 타일에 클립 순서 번호를 표시하고 시간은 고정폭 숫자 유지.
- 선택 클립 경계와 실제 재생 헤드 강조를 구분.
- 시작/끝 드래그 핸들에 접근성 설명 및 테스트 태그 추가.
- 길게 눌러 순서 변경, 비선택/선택, 좌우 트림, 1~16배 줌 및 LazyRow 가상화 로직은 불변.

## 필수 테스트

- Android 기존 `EditorDesignInstrumentedTest` 내 빠른 편집 결과/범위/저장 상태, 상세 편집 도구 접근성·원본 구간 유지 검증.
- `TimelineStripInstrumentedTest`의 기존 100개 클립 LazyRow, 줌, 드래그·순서 변경 검증 및 핸들 존재 단언.
- 기존 테스트 개수는 변경하지 않아 API 29의 정확한 292개 계측을 유지.
- 기존 미디어 픽스처로 만든 실제 Android 화면 4장: `editor_design_{quick_trim|detailed}_{light|dark}.png`. `android-instrumentation-check.sh`의 PNG 무결성 게이트에 필수 등록하고, `test-emulator-flow.py`에서 손상 파일 차단 확인.
- `editor_design_quick_trim_result.png` 별도 캡처는 입력 후 결과 요약까지 실제 스크롤 가능한지 확인하기 위한 보조 증거.
