## 변경 범위

### 1. 내보내기 품질/저장 설정
- 자동/수동 품질 안내를 현재 실제 저장 정책에 맞게 교정: 원본 품질/FPS 유지, 가능한 경우 고속 저장, 직접 설정 시 재인코딩 승인.
- 원본 선택 영상 프레임 → 해상도 → FPS → 압축 품질 → 예상 출력 결과 정보 위계를 정리. 작은 화면에서 품질 옵션은 가로 스크롤해 48dp 이상의 접근성을 확보.
- 실제 `ExportQualityInspector` 평가가 지원하지 않는 설정일 때 '저장할 수 없음'과 원인을 명시. `SaveOptionsDialog` 저장 버튼 비활성 정책은 그대로 보존.
- 저장 위치(기기 갤러리) → 날짜 설정 → 원본 유지/휴지통/삭제 순으로 설정 정보를 정렬.
- 예상 출력 용량은 추정치임을 명시. 인코더/품질 정책·최대 FPS/해상도 지원 계산·비밀키/Play 설정 불변.

### 2. 내보내기 진행
- `CenterStatus`에서 실제 단계명과 가능한 경우에만 실제 단계 진행률을 표시. 진행률을 확인할 수 없는 단계는 불확정 막대를 사용하고 가상의 진행률을 만들지 않음.
- '영상 불러오기' 및 '영상 내보내기' 구분, 취소 가능한 단계에서만 취소 버튼 노출, 최종 갤러리 등록 때는 기존 취소 불가 정책 유지.
- Android 백그라운드 내보내기·복구·중단 로직, 단계 `ExportStage`·`progressPercent` 및 `onCancel` 콜백 유지.

### 3. 저장 완료
- 출력물 미리보기, 출력 결과(저장 위치·날짜 설정·실제 변환 방식·실제 파일 메타데이터), 원본 처리 승인/진행 상태, 갤러리 열기/공유/새 영상 편집 순서로 정리.
- 결과 영상/원본/하단 동작 섹션에 테스트 태그 부여. 3D/그라데이션/성공 장식 없이 단색 중성 계열.
- `CompletedExportFacts`는 실제 URI를 통해 읽을 수 있을 때만 해상도·FPS·용량을 표기. 미확인 저장 경로·실제 파일 정보를 임의로 만들어 표시하지 않음.
- 원본 유지/휴지통/영구 삭제, SKIPPED 재요청, Android 원본 승인 콜백 불변.

## 검증 범위

- 기존 `Stage15ExportQualityScreensInstrumentedTest` 1개 계측 테스트: 자동/수동/미지원 출력과 저장 버튼 비활성, 실제 Android 비디오 픽스처를 가진 완료 화면의 UI 렌더/스크롤 확인.
- 기존 `ExportStage5InstrumentedTest` 2개 테스트: 실측 단계값(테스트 상태 45%)·취소 콜백/완료 단계에서 취소 없음 검증.
- 추가 UI 캡처: `ui05b_export_progress.png`, `ui05b_export_finalizing.png`, `ui05b_export_completed.png`. 전부 Android 런타임 캡처이나, 완료 UI는 기기의 MP4 픽스처를 사용하고 실제 앱 내보내기 완료 증명과는 **구분**.
- `scripts/android-instrumentation-check.sh`에서 위 3개 PNG의 실제 파일 존재/PNG CRC/크기 검증을 필수화. `scripts/test-emulator-flow.py`에서는 가짜 ADB 오류/손상된 완료 이미지 거부를 회귀 확인.
- API 29 292개 기존 Android 계측 테스트 수 변경 없음. API 35/36 전체 전수 계측을 기존 CI에서 실행.
- 실제 인코딩 MP4/AAC 품질, 완료 후 갤러리 등록, 중단/원본 SHA 및 프로젝트 복구는 기존 Stage19/20 미디어 계측 게이트에서 별도 검증. 정적 완료 화면 픽스처로 이를 대체하거나 통과 처리하지 않음.
