QuickCut 개인정보처리방침
시행일: 2026년 11월 16일
운영자: hebi (QuickCut 개발자)

1. 기기 내 영상 처리
QuickCut은 사용자가 선택한 영상·음성·촬영 날짜·영상 형식과 길이 등 메타데이터를 자르기, 분할, 연결, 음소거 및 결과 저장을 위해 기기 안에서 처리합니다. 앱 계정이나 로그인이 없으며, 원본 영상이나 편집 결과를 개발자 서버로 업로드하지 않습니다. 광고 SDK를 통한 별도 데이터 처리 내용은 7항을 참고해 주세요. 앱은 사용자가 선택한 영상 콘텐츠를 광고 SDK에 전달하지 않습니다.

2. 선택한 파일과 권한
Android 문서 선택기에서 사용자가 고른 영상에만 접근합니다. 전체 사진·영상 보관함, 위치, 연락처, 카메라, 마이크 접근 권한을 요청하지 않습니다. 선택한 파일이 클라우드 문서 제공자에 있으면 해당 제공자가 파일을 내려받을 수 있으며 그 제공자의 정책이 적용됩니다.

3. 기기에 보관하는 설정과 작업 기록
선택한 원본의 URI(파일을 다시 여는 주소), 편집 구간·순서·음소거 설정, 템플릿, 저장 날짜·원본 처리 설정, 이전 편집과 일괄 작업 복구 기록을 앱 내부 저장소에 보관합니다. 자동 Android 앱 데이터 백업은 사용하지 않습니다. 광고 개인정보 동의는 Google UMP SDK가 별도로 관리합니다. 임시 결과는 앱 캐시 또는 갤러리의 임시 항목에 저장하며 완료한 결과는 갤러리의 Movies/QuickCut 폴더에 저장합니다. 정상적인 정리 절차에서 임시 결과를 제거하며, 미완료 작업은 다음 실행 시 복구·정리할 수 있습니다.

4. 로컬 진단과 클립보드
문제 확인을 위해 최근 작업 최대 12건과 실패 작업 최대 6건의 진단을 기기에 보관합니다. 앱 버전, 기기 모델·Android 버전, 코덱·영상 형식·길이·크기, 처리 단계와 시간, 저장 공간, 분류된 오류 정보 등을 포함합니다. 진단에는 원본 URI·경로·파일명·영상 내용·원시 오류 메시지를 넣지 않습니다. 진단은 자동 전송하지 않으며 사용자가 '진단 복사'를 누를 때만 클립보드로 복사됩니다. 이후 사용자가 다른 앱에 붙여넣어 공유하면 해당 앱의 정책이 적용됩니다.

5. 백그라운드 저장과 원본 처리
사용자가 시작한 영상 저장을 다른 앱 사용 중에도 완료하기 위해 진행 알림이 있는 포그라운드 서비스를 사용합니다. 알림에서 진행 상태를 확인하고 저장을 중단할 수 있습니다. 원본은 기본적으로 유지합니다. 원본 휴지통 이동·영구 삭제는 사용자가 해당 옵션을 선택하고 저장 후 Android의 시스템 승인 절차를 거친 경우에 수행합니다. Android 10에서는 원본 자동 처리를 지원하지 않습니다.

6. 삭제와 보관
앱 설정의 데이터 삭제 또는 앱 제거로 내부 설정·템플릿·복구 기록·진단을 삭제할 수 있습니다. 갤러리에 저장한 완성 영상과 원본은 앱 제거 후에도 남을 수 있으므로 갤러리나 파일 관리 앱에서 별도로 관리·삭제해 주세요. 앱이 보관한 기록은 다음 작업과 설정 변경에 따라 갱신되며 진단은 정해진 건수까지만 유지합니다.

7. 광고 SDK 및 제3자 데이터 처리
QuickCut은 홈 화면 하단에 Google AdMob 배너 광고를 표시할 수 있습니다. 광고는 광고 SDK가 활성화되고, Google UMP(User Messaging Platform)의 동의 상태에서 광고 요청이 허용된 경우에만 요청합니다. 지역별로 동의 양식이 필요한 경우 이를 먼저 표시하며, 해당하는 경우 설정에서 광고 개인정보 선택을 변경할 수 있습니다. 동의가 확인되지 않으면 광고를 요청하지 않습니다.

Google의 광고 SDK는 광고 제공, 광고 성과 측정, 부정 사용 방지 등을 위해 광고 식별자, IP 주소, 기기·앱 정보, 광고 상호작용 정보 및 진단 정보를 수집·처리할 수 있습니다. 구체적인 처리 범위는 사용자의 기기·동의 상태·광고 설정과 Google의 정책에 따라 달라집니다. 원본 영상·음성 콘텐츠, 편집 구간·프로젝트 이름, 파일 URI와 저장한 영상은 광고 요청에 포함하지 않습니다. Google 개인정보처리방침: https://policies.google.com/privacy
Google Mobile Ads SDK의 데이터 공개 안내: https://developers.google.com/admob/android/privacy/play-data-disclosure

앱은 광고 제공을 위한 Google SDK 이외의 별도 사용자 행동 분석 서비스나 자체 사용자 계정 서버를 운영하지 않습니다. 외부 문서 제공자 사용, 클립보드 공유, 직접 보내는 문의 이메일은 해당 외부 서비스의 정책이 적용됩니다. 광고 제거 구매 기능은 별도 결제·권한 검증이 구현된 이후 제공될 수 있습니다.
