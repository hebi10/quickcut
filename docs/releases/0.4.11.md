# QuickCut 0.4.11

이번 업데이트는 고속 저장의 종료 경계, 중단 복구, 편집 화면과 배포 검사를 보완합니다.

- 뒤쪽부터 재생 순서가 바뀌는 영상에서 종료 직전의 보존 대상 프레임을 빠뜨리지 않도록 직접 복사 경계를 검사합니다. 안전성을 확인하지 못한 경계는 기존 네이티브 처리 또는 사용자 동의가 필요한 정확한 저장 경로로 넘깁니다.
- PR #7의 단일·일괄 저장 복구, 미확인 출력/손상 기록 보존, 상세 편집 재생 위치·입력값, Android 10 프레임·소리 시각 보완을 포함합니다.
- 템플릿 삭제 기록에 실패하면 앱을 종료하지 않고 실패를 안내하며 기존 목록과 선택을 유지합니다.
- 상세 편집 타임라인은 화면에 필요한 클립부터 구성하고 클립 시작 위치를 미리 계산합니다.
- 앱 소스·설정·리소스와 빌드 설정 변경에 기기 검사를 실행합니다. 같은 main 커밋의 Android 빌드 및 API 29·35·36 검사 성공을 확인한 뒤 APK를 생성·공개합니다.
- README에 Linux x86_64 네이티브 엔진 준비와 Android 빌드 순서를 명시합니다.

버전은 **0.4.11 / versionCode 16**이며 Android 10 이상, arm64-v8a·x86_64를 지원합니다. 기존 고정 배포 인증서를 검사해 서명합니다. 같은 인증서의 기존 앱은 삭제하지 않고 업데이트할 수 있습니다.

APK, 대응 소스, 소스 안내와 SHA-256 목록을 함께 제공합니다. 정확한 배포 커밋·검사 실행·서명 확인은 릴리스의 소스 안내와 GitHub Actions에서 확인할 수 있습니다.

자동 검사는 실기기 성능 검증을 대신하지 않습니다. **Fold8 실기기와 사용자가 보고한 실제 3시간 원본은 접근하지 못했으며 해당 원본 오류 해결을 확인하지 않았습니다.** 원본을 유지한 채 앞·중간·끝 자르기, 화면 끄기/앱 전환, 영상·소리 동기 및 HDR 재생을 추가 확인해야 합니다. 재현 방법은 [대용량 원본 실기기 QA](../27_LARGE_SOURCE_DEVICE_QA.md)에 있습니다. 모든 영상의 고속 처리를 보장하지 않습니다.
