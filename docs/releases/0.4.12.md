# QuickCut 0.4.12

Android 앱 버전 `0.4.12`, versionCode `17`.

## 변경 사항

- 여러 편집 프리셋을 하단에서 선택하고, 새 복사본 저장과 선택한 프리셋 갱신을 구분합니다.
- 일괄 원본 휴지통/영구 삭제는 활성화 시 앱 확인을 거칩니다. 확인한 선택은 원본 유지로 바꾸기 전까지 앱 재실행·재편집 후에도 유지됩니다. 실제 처리는 매 실행에서 새로 저장에 성공한 원본에 한해 Android 승인을 별도로 요청합니다. 복구한 이전 완료 출력의 원본은 삭제 대상에 넣지 않습니다.
- 유효한 고속 저장 추천 위치는 기본 선택으로 표시합니다. 표시된 실제 저장 구간과 추가 삭제 길이를 확인하고 경계·연결부를 미리 본 뒤 승인하며, 파일별로 현재 위치 유지·추천 위치 사용·제외를 선택할 수 있습니다.
- 저장 중 실제 처리 단계를 표시하고 단계 전환·재시도 시 해당 진행률을 다시 시작합니다. 화면을 벗어나거나 저장을 시작하면 미리보기를 멈추고, 복원 후에는 일시정지 상태를 유지합니다.
- 진단에는 분류된 오류 코드와 처리 단계·형식·기기·저장 공간 등의 메타데이터만 기기 내부에 기록합니다. 원본 URI·경로·파일명·영상 내용·원시 오류 메시지를 기록하거나 자동 전송하지 않습니다.

## 검증 및 배포 기준

빌드·JVM 검사·Lint·네이티브 출력 검사와 Android API 29·35·36 계측 검사를 사용합니다. 서명 배포는 버전을 선언한 정확한 현재 `main` 커밋에서 `Android build`와 `Android emulator smoke`의 최신 실행이 모두 성공하고, 같은 버전의 태그와 릴리스가 없을 때만 허용합니다. 이전 PR의 성공 결과로 새 릴리스 검증을 대신하지 않습니다. 실행 상태는 [Actions](https://github.com/hebi10/quickcut/actions)에서 확인할 수 있습니다.

설치용 APK는 기존 QuickCut 고정 인증서와 버전 정보를 확인한 뒤 배포합니다. 서명 정보가 없으면 외부 서명용 준비물만 만들며, 서명 없는 APK를 설치용 릴리스로 게시하지 않습니다.

모든 영상의 고속 저장이나 특정 기종의 동작을 보장하지 않습니다. 사용자가 보고한 3시간 원본의 개별 오류는 아직 재현하지 못했으며, 실제 기종의 긴 영상·고해상도·대량 일괄 작업 검증은 계속 필요합니다.
