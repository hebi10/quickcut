# QuickCut 0.4.13

‘포켓 컷 스튜디오’ 컨셉으로 앱의 이미지를 새로 만들고 화면을 정리했습니다.

- 이미지 생성으로 제작한 민트·살구색 필름 아이콘과 시작 화면 그래픽을 적용했습니다. 기본·둥근 런처와 Android 테마 아이콘을 지원합니다.
- 잉크색 배경, 민트색 주요 동작, 살구색 보조 강조와 둥근 패널을 단일·상세·일괄 편집에 공통 적용했습니다.
- 시작 화면에서 세 편집 방식을 설명과 함께 선택하고 이전 작업과 설정을 쉽게 찾을 수 있습니다. 펼친 화면에서는 두 열을 사용합니다.
- 영상 미리보기의 검은 배경을 유지하고, 편집 도구·삭제 구간·파일 목록·저장 상태의 시각적 구분을 보강했습니다.
- 좁은 화면·가로 화면·큰 글자·Fold 크기에서 시작 동작에 접근할 수 있는지 검사합니다.

버전 `0.4.13` / versionCode `18`, Android 10 이상, arm64-v8a·x86_64.
영상 처리·저장 동의·원본 처리·프리셋·재편집 상태의 기능은 유지합니다. 이번 변경으로 실제 사용자 원본의 처리 오류 해결을 새로 확인한 것은 아닙니다.

빌드와 정확한 배포 소스의 Android API 29·35·36 검사를 확인한 후 기존 고정 인증서로 서명합니다. APK와 정확한 대응 소스·소스 안내·SHA256SUMS를 함께 제공합니다.
