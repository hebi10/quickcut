# QuickCut 0.4.14

편집 기록과 완성본을 보호하고, 일부 영상의 처리 실패 원인을 확인하고 재시도할 수 있도록 보강했습니다.

- 원본을 일시적으로 읽지 못해도 저장한 편집 기록을 지우지 않습니다. 복원을 다시 시도하거나 같은 원본을 다시 선택해 연결할 수 있습니다. 연결 전 전체 해당 구간을 검사하고 순서·정밀 범위·음소거·재생 위치를 유지합니다.
- 불러오기 화면에서 취소하거나 뒤로 갈 수 있습니다. 늦게 끝난 이전 불러오기가 새 작업을 덮어쓰지 않습니다.
- 미리보기 오류 뒤에는 **미리보기 다시 시도**로 재생 자원을 새로 준비합니다. 오류 시점의 잘못된 0초 위치가 편집 위치를 덮어쓰지 않도록 보호합니다.
- **최근 작업 진단**에 불러오기·복원·미리보기·저장 방식 확인을 포함합니다. 재생 오류와 저장 오류의 코드 체계를 구분하며 원본 URI·경로·파일명·예외 원문을 진단에 넣지 않습니다. 기록은 기기 안에 보관됩니다.
- 복구 가능한 Media3 코덱 오류와 프레임 누락은 하나의 예산으로 최대 한 번 추가 시도합니다. 이전 처리 자원을 해제한 뒤 새 임시 파일로 시작합니다. 영구 오류·취소·권한·저장소 오류를 무조건 반복하지 않으며 해상도·HDR·화질을 임의로 낮추지 않습니다.
- 갤러리 등록 뒤 완료 기록 쓰기에 실패해도 이미 완성된 영상을 지우지 않습니다. 일괄 작업은 경고와 복구 상태를 유지하며 확인 전 중복 저장·원본 삭제를 막습니다. 등록 전 실패한 임시 항목은 계속 정리합니다.
- 네이티브 분석의 프레임·색인 메타데이터에 작업별 64MiB 요청 할당 예산을 적용합니다. 범위를 넘으면 이유를 표시하고, 사용자가 허용한 경우 정확한 자동 저장으로 전환합니다. 이 예산은 FFmpeg 버퍼나 전체 앱 메모리 상한을 뜻하지 않습니다.

버전 `0.4.14` / versionCode `19`, Android 10 이상, arm64-v8a·x86_64.
기존 포켓 컷 스튜디오 디자인·여러 템플릿·원본 처리 설정·저장 동의와 정밀 경계를 유지합니다.

원본 데이터 복사도 파일 쓰기와 검사 시간이 필요하며 진행률 표시가 재인코딩을 뜻하지는 않습니다. 구간·코덱·컨테이너·HDR 조건에 따라 재인코딩이 필요할 수 있습니다. 모든 영상의 무재인코딩이나 오류 없는 처리를 보장하지 않습니다. 실제 사용자 실패 영상과 물리 Fold8은 확보하지 못해 해당 문제의 재현·해결 여부는 별도 확인이 필요합니다.

배포 전 정확한 main 소스의 빌드와 Android API29·35·36 검사를 요구합니다. 기존 고정 인증서로 서명한 APK에 정확한 대응 소스·소스 안내·SHA256SUMS를 함께 제공합니다.
