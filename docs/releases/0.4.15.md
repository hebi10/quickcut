# QuickCut 0.4.15

- 새 저장 설정의 날짜 기본값을 **원본 날짜 유지**로 변경했습니다. 사용자가 이미 저장한 날짜 선택과 복원 중인 작업의 날짜는 유지합니다.
- 편집 방식의 **앞뒤 구간 삭제**를 **앞뒤 구간 자르기**로 바꿨습니다. 실제로 남기는 영상 구간은 같습니다.
- 편집 방식, 저장 날짜, 원본 처리와 파일별 저장 위치를 드롭다운에서 선택합니다. 원본 자동 처리 활성화 확인은 유지합니다.
- 일괄 편집의 템플릿 선택·새 저장·수정·삭제를 세로 목록 모달로 옮겼습니다. 기존 템플릿과 현재 편집값은 유지합니다.
- **추천 위치로 고속 저장**과 **선택한 설정으로 저장** 버튼을 확인 화면의 고정 하단 영역에 함께 배치했습니다.
- 고속 저장 도중 재인코딩이 필요하다고 확인된 요청은 같은 고속 경로로 반복 재시도하지 않습니다. 원래 요청 구간과 안내를 확인하고 정확한 위치 저장에 동의하면 재인코딩을 허용해 다시 저장할 수 있습니다. 완료 파일과 확인되지 않은 출력은 기존 복구 보호를 따릅니다.
- `ReencodeRequiredException` 진단에 읽기 쉬운 설명을 제공합니다. 이 예외는 재인코딩 없이 안전하게 저장할 수 없다는 뜻이며, 모든 영상의 무인코딩 저장을 보장하지는 않습니다.

버전 코드: 20. 기존 서명 인증서로 업데이트를 제공합니다.

실제 사용자 실패 영상과 물리 Fold8 테스트는 아직 수행하지 못했습니다. 검증 결과와 다운로드는 GitHub 릴리스에 기록합니다.
