# QuickCut 0.4.17

Android 10 이상 · 버전 코드23.

- 일괄 편집에서 영상 선택 전에는 추가 버튼, 선택 후에는 저장 버튼을 강조합니다.
- 편집 방식과 저장 옵션의 선택 메뉴를 보조 스타일로 정리하고 선택 표시와 메뉴 폭을 개선했습니다.
- 빠른 자르기와 상세 편집의 결과 시간, 재생 컨트롤, 원본 소리 상태와 저장 명칭을 통일했습니다.
- 원본에서 남길 구간과 타임라인 확대 배율을 명확하게 표시합니다.
- 중복 안내와 중첩 패널을 줄이고 저장할 수 없는 이유를 표시합니다.
- 빠른 자르기의 증감 버튼과 초 입력칸 높이를 맞추고 큰 글꼴에서도 함께 늘어나도록 개선했습니다.

영상은 기기 내에서 처리합니다. 기존 정밀 시간 입력, 저장 날짜 선택과 원본 처리 동의, 템플릿·복구 동작을 유지합니다.
