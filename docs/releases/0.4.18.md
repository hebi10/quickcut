# QuickCut 0.4.18

Android 10 이상 · versionCode 24.

- 홈 화면의 편집 모드와 안내 정보를 더 명확하게 정리했습니다.
- 빠른 자르기의 초 입력창과 증감 버튼 높이를 통일하고 결과 시간을 강조했습니다.
- 일괄 편집에서 영상 선택, 템플릿, 자르기, 저장 순서를 정리했습니다.
- 정확한 위치로 저장과 추천 위치 고속 저장의 차이를 명확히 표시했습니다.
- 저장 설정의 원본 삭제 안내와 미리보기 오류·저장 완료 화면을 개선했습니다.

영상 처리는 기존과 같이 기기 내에서 수행합니다. 편집 기능과 원본 처리 정책은 유지됩니다.
