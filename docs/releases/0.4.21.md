# QuickCut 0.4.21

Android 10 이상 · 기본 versionCode 28.

- 영상 한 개에서 여러 구간을 지정해 개별 MP4로 저장하고 성공·실패 구간을 구분해 복구합니다.
- 해상도, 프레임레이트, 압축 화질을 선택하며 미지원 출력 조합은 사전에 안내합니다.
- 9:16·1:1·16:9·자유 크롭, 오디오 볼륨·페이드 및 시간 지정 텍스트 오버레이를 지원합니다.
- 크롭·오디오·텍스트·화질을 동시에 적용하는 미리보기 및 MP4 저장 경로를 통합합니다.
- 구형 프로젝트 복원, 중단된 저장 기록, 재인코딩 동의 및 Android API별 검증 증거를 강화합니다.
- 기존 빠른 자르기·일괄 편집·템플릿과 원본 유지·삭제 승인 정책은 변경하지 않습니다.
