# QuickCut 검토 후속 보완

해비님이 2026-10-23 검토의 모든 개선 항목 구현을 요청했다. 기존 Kotlin/Compose, Media3, Rust/FFmpeg 구조와 원본 보호·명시적 재인코딩 동의를 유지한다.

## 범위와 설계

- 상세 편집 미리보기의 현재 구성과 위치를 함께 관리한다. 일시정지/분할은 최신 위치를 반영하고 구성 변경 후 이전 콜백을 거절한다.
- 일괄 복구의 조회 불확실성·기록 손상·쓰기 실패를 파일 없음과 구분한다. 출력 소유권과 완료 검증 기준을 단일 저장과 공유한다.
- 유효한 all-intra AVC의 복사 경로를 허용하며 추천과 저장의 공통 지원 조건을 검사한다. 경계 재인코딩의 안전 검사를 완화하지 않는다.
- 최초 분석의 중복 I/O는 안전 검증을 보존하는 범위에서 통합한다. 단계별 처리 시간을 진단에 기록하고 대용량 검증 절차를 재현 가능하게 만든다.
- 최근 저장 기록과 최근 실패 기록을 구분하여 제한된 개수만 기기 내부 보관한다. 원본 경로·URI·파일명·원시 오류·영상 내용을 저장하거나 전송하지 않는다. 일괄 결과에서 해당 작업의 진단을 찾을 수 있도록 비민감 작업 ID로 연결한다.
- 선택 그룹의 접근성 의미를 보완한다. 새 시각 효과나 새 제품 기능을 추가하지 않는다.
- 변경 영역의 미리보기 동기화·복구·진단 책임을 작은 모듈로 추출한다. 전면 재작성은 하지 않는다.
- Fold8 및 사용자 3시간 원본은 제공되지 않았으므로 자동 검증과 실기기 미검증을 명시한다. 실기기 검증 완료를 주장하지 않는다.

## 접근 방식

기존 경로의 검증과 공통 모듈을 보강한다. 엔진 전면 교체는 검증된 동작을 잃는 비용이 크고, 제한 조건만 제거하는 방법은 출력 안전성을 해칠 수 있어 채택하지 않는다. 새 의존성 없이 현재 테스트 체계에 회귀 검사를 추가한다.
