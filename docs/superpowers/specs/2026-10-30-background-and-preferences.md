# 백그라운드 저장과 편집 설정

사용자가 확인한 요청: 다중 템플릿을 하단에서 선택·추가, 원본 처리 설정을 활성화 확인 후 지속, 권장 시점을 기본 선택 및 주요 저장 동작으로 강조, 실제 저장 방식에 맞는 진행 표시, 화면 끄기·앱 전환 중 정상 영상 저장 오류 개선. 기존 Kotlin·Compose 구조와 사각형 UI를 유지한다. 새 의존성·외부 전송은 추가하지 않는다.

## 선택과 범위
기존 foreground service/wake lock을 재사용한다. 무제한 재시작·시간 제한 해제는 사용하지 않는다. 미리보기는 보이지 않을 때 디코더 자원을 반납하고 돌아오면 위치를 보존한 채 준비하되 자동 재생하지 않는다. 실패 원인은 메시지/경로 없이 허용된 엔진·Media3 코드·코덱 자원 상태만 기기 내 기록한다. 실제 Fold8/사용자 원본은 없으므로 해당 오류 재현·해결을 단정하지 않는다.

템플릿 저장 형식과 최대 30개를 유지한다. 하단에 목록을 항상 표시하고 선택 항목 수정과 새 이름 저장을 분리한다. 원본 처리의 확인된 선호값은 KEEP 기본, TRASH/DELETE 활성화 때 확인 후 저장한다. 사용자가 KEEP으로 바꿀 때까지 새 작업·재편집·앱 재시작에도 유지한다. 실행 중 작업의 선택값과 새 작업 선호값, 완료 출력별 삭제 후보를 분리한다. 실패·취소·건너뜀·복구된 이전 출력의 원본은 자동 삭제하지 않는다. Android 승인과 거절 후 재시도는 유지하고 앱 자체의 완료 후 중복 경고만 없앤다.

권장 범위가 유효한 파일은 검토 화면에서 권장 선택을 기본으로 한다. 요청/권장 시각을 보여 준 뒤 사용자의 저장 클릭으로 승인한다. 권장 불가 파일의 정확한 저장·건너뛰기 선택을 유지한다. 진행률은 단계 전환 때 초기화하고 실제 엔진/엔코더 근거 이상을 주장하지 않는다. 최종 실제 방식은 ExportReport를 유지한다.

## 검증
설정 활성화 취소/확인/해제/재활성화와 모델 재생성·재편집, 새 템플릿의 기존 항목 비덮어쓰기, 권장 기본 선택과 검토 동의, 미리보기 정지/복원과 실제 Media3 변환 도중 화면 끄기·앱 전환, 오류 코드 기록의 경로/메시지 비노출을 회귀 검사한다. 원본/출력 무결성·공개 횟수·실패 정리 계약을 유지한다.
