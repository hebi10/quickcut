# QuickCut Play 등록

목표: 기존 QuickCut 기능과 공식 서명 연속성을 유지하면서 Google Play 등록 자료와 AAB를 준비하고 사용자 계정에서 제출한다.

기준: GitHub main 3cad2ab71e3d4778f728eb7e007eb23597d0d1e2, tree ebbd16c951978ceb61a38de36a4c84c684860f57. 원본은0.4.15/code20. 스토어 지원 이메일 asdlkj0104@gmail.com은 사용자가 공개 용도로 승인했다. 앱 생성의 개발자 정책과 미국 수출법 동의도 승인했다.

접근: 기존 Kotlin/Compose 화면에 오프라인 개인정보처리방침 전문 진입점만 추가한다. 새로운 SDK, 인터넷 권한, 분석/광고는 추가하지 않는다. 공개 정책은 같은 저장소의 버전 관리 문서로 제공한다. 스토어에는 로컬 처리와 고속 저장의 실제 한계를 정확하게 설명한다. 단순 외부 URL만 추가하는 방식보다 오프라인 전문이 접근성과 심사 재현성을 높인다.

배포:0.4.16/code21. CI에 bundleRelease와 unsigned AAB artifact를 추가하고 APK·단위·린트·기기 검사를 유지한다. AAB는 JAR 방식으로 기존 공식 인증서로 서명한다. Play 앱 서명 키 설정은 기존 외부 설치와 업데이트 호환성을 확인한다. 새로운 법적 약관 또는 개인 키 외부 이전은 해당 화면에서 필요한 승인만 별도로 받는다.

개인정보: 영상/오디오/촬영 날짜는 기기 내 편집 처리, 선택 URI·설정·템플릿·작업 복원 기록·제한된 로컬 진단 보관, 임시 파일·갤러리 결과 구분, 복사 시 클립보드, 사용자 선택과 Android 승인 원본 처리, 삭제 방법, 공개 연락처와 시행일을 설명한다. 앱 사용자 계정·서버·광고·분석·자동 업로드는 없다.

범위: 개인정보 모달과 진입점, 공개 정책, 정확한 GPL 소스 경로 안내, AAB CI/버전·배포 설명, 스토어 자료와 실제 콘솔 신고. 영상 엔진·기존 사용자 편집 흐름·브랜드는 변경하지 않는다.
