# QuickCut 편집 화면 정리

사용자가 승인한 디자인 피드백을 버튼 강조 → 시간·상태 표시 → 일괄 편집 밀도 순으로 반영한다. 다크 그린·민트 브랜드와 기존 Kotlin/Compose 구조를 유지한다.

- 설정 선택기는 보조 강조로 낮추고 메뉴 폭을 앵커에 맞춘다. 선택 체크, 현재값 semantics, disabled 상태, 최소 48dp 조작 영역을 보존한다.
- 빈 일괄 편집은 영상 추가를 강조하고 선택 개수와 저장 비활성 이유를 가까이 표시한다. 시간 입력의 반복 안내와 불필요한 중첩 박스를 줄인다. 기존 저장 옵션 접기·현재값 요약과 결과에 영향을 주는 경고를 유지한다.
- 빠른/상세 편집의 저장 명칭과 소리 상태를 통일한다. 시간은 원본·결과 기준을 구분해 0.1초 표시를 일관되게 사용하되 실제 ms 경계와 입력값을 변경하지 않는다. 남길 원본 구간을 표시한다.
- 타임라인 배율에 확대라는 목적을 표시한다. 빠른 미리보기의 초 단위가 잘리는 기본 컨트롤을 기존 Compose 재생/탐색 표현과 맞춘다. 재생·seek·화면 중단/복귀 동작을 유지한다.
- 헤더의 불필요한 영문 브랜딩과 과도한 박스를 덜어 일관된 뒤로가기/제목 구성을 사용한다. 기존 반응형 분기와 큰 글꼴 지원을 유지한다.
- 저장·원본 삭제 동의·복구·고속 처리·native 엔진·의존성·앱 버전과 서명 설정은 변경하지 않는다.

완료 기준: 기존 단위/Lint/기기 검증을 통과하고 실제 Android 에뮬레이터에서 일괄 편집(빈 상태/선택/메뉴), 빠른 자르기, 상세 편집 캡처를 확인해 사용자에게 제공한다. 저장 옵션의 파괴적 선택 확인과 정밀 시간 회귀 검증을 유지한다.

작업 방식: 기존 UI만 정리한다. 새 테마나 탐색 구조를 도입하는 대안은 사용자 승인 범위보다 크므로 채택하지 않는다. 화면별 파일 경계가 분리되어 있어 공유 선택기를 먼저 수정한 후 일괄/개별 편집을 독립적으로 반영한다.
