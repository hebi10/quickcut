요청한 위치에서 고속 저장하기 어려울 때, 영상 복사가 가능한 추천 위치와 추가로 잘리는 길이를 보여줍니다.

- 시작·끝과 중간 삭제 구간의 요청 시간, 추천 시간, 추가 삭제 길이를 표시합니다.
- **추천 위치로 고속 저장**을 선택해야 조정합니다. **정확한 위치로 자동 저장**과 **취소**도 선택할 수 있습니다.
- 삭제하려던 장면을 다시 포함하지 않고 더 잘라내는 방향으로만 추천합니다. 일괄 저장은 파일마다 조정 내용과 건너뛸 파일을 안내합니다.
- 고속 전용 저장은 영상 재인코딩으로 자동 전환하지 않습니다. 소리는 필요하면 변환합니다.
- 긴 영상 분석을 취소할 수 있고, 저장 실패 후 방식을 다시 고를 때 불필요한 분석을 반복하지 않습니다.

키프레임 간격에 따라 조정 폭은 수 초 이상일 수도 있습니다. 모든 영상에 추천 위치가 있는 것은 아니며, 안전한 위치를 찾지 못하면 정확한 위치로 자동 저장할 수 있습니다.
